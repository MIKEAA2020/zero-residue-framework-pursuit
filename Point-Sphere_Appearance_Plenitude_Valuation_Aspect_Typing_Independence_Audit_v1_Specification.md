# AP3P2D Valuation-Algebra and Aspect-Typing Independence Audit v1
## Does the protected core select fibre-local versus cross-sector valuation content, or type lift classes as aspects?

## Purpose

AP3P2C gives an exact conditional fork:
\[
\mathcal A_{\rm loc}\Rightarrow H_{\rm full}\text{ may be gauge};
\qquad
\mathcal A_{\rm rel}\Rightarrow H_{\rm uniform}\text{ may be gauge and eight relative classes remain}.
\]

AP3P2D tests whether the protected core plus completed AP3 typing chooses either valuation algebra, or entails that non-gauge lift/orbit classes are genuine aspects subject to conditional plenitude.

## Common typed base

Both models retain:

- one non-structural \(G\), not represented as a phase node;
- finite bounded phase contexts;
- intrinsic bi-infinite successor structure, not external time;
- internal retentional trace values \((r_0,r_1)\);
- no subject/object monitor or external carrier;
- nonexclusive coexistence of distinct declared flow components.

The protected core identity classifies genuine modes/aspects/content of self-knowledge. It does not syntactically contain a global Q-bit section, cross-sector observable, or map from a quotient of formal lift laws to the admissible aspect domain.

## Rival models

### L — fibre-local description model

Q free-bit values are chart coordinates only. No cross-sector comparison is defined. Full \(H_{\rm full}\cong(\mathbb Z_2)^4\) is declared description gauge, yielding one lift class.

### R — relational aspect model

Cross-sector relative-bit signature:
\[
I(d)=\bigl(I_{00,01},I_{00,10},I_{00,11}\bigr)\in(\mathbb Z_2)^3
\]
is declared intrinsic. Uniform complement is gauge; the eight values of \(I\) are distinct flow-aspect candidates. If and only if this candidate set is explicitly admitted to \(\mathcal A\), conditional plenitude realizes all eight nonexclusively.

### M — meta-law model

Lift classes are alternative formal continuation laws, not aspect contents. Neither gauge quotient nor plenitude automatically turns them into aspects.

## Registered question

Construct all three as coherent extensions of the common typed base. If all survive, then:
\[
K+\text{AP3 typing}\not\models
\mathcal A_{\rm loc},\quad
\mathcal A_{\rm rel},\quad\text{or aspect membership of lift orbits}.
\]

No-preference does not select among these. Conditional plenitude applies only after genuine aspect-domain typing is supplied.

## Success condition

The audit is successful if it makes the remaining input exact rather than silently forcing a selector:

> An independent valuation-content law must say whether cross-sector Q-bit relations are intrinsic, and an independent aspect-typing law must say whether non-gauge quotient classes are genuine aspects rather than formal alternatives.
