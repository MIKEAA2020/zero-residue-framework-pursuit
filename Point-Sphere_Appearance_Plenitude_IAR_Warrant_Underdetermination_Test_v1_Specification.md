# AP3H IAR Warrant-Underdetermination Test v1
## Does the aware-ground core determine a self-presentability compatibility relation?

## Question

AP3G supplied a usable formal membership candidate only by stipulating a self-presentability compatibility relation \(\smile\). This test isolates whether the existing aware-ground commitments, taken without an additional formal aspect law, determine that relation.

## Frozen comparison

Use the same six-content vocabulary
\[
\mathcal S=\{r_0,r_1,p_s,p_v,q_s,q_v\}.
\]
Compare three relation families:

1. **Universal compatibility \(\smile_U\):** every pair of contents is jointly self-presentable. The sole maximal context is \(\mathcal S\), so there is no proper bounded maximal context.
2. **IAR two-context compatibility \(\smile_{\rm IAR}\):** exactly the AP3G relation, yielding proper maximal contexts \(C_P\) and \(C_Q\).
3. **Discrete compatibility \(\smile_D\):** only each content with itself. The maximal proper contexts are the six singleton contents.

The ground is not represented as an element of any model. The test does not model awareness. It formalises only the logical point: the prose commitments “complete,” “self-knowing,” and “nondual self-presentation” contain no currently supplied mathematical axiom that selects one of these relation families.

## Registered claim

All three relation families are compatible with the bare formal typing of a simple aware ground because no existing framework equation or axiom constrains \(\smile\). They yield incompatible mode taxonomies:

\[
\#\operatorname{MaxPropCtx}(\smile_U)=0,
\quad
\#\operatorname{MaxPropCtx}(\smile_{\rm IAR})=2,
\quad
\#\operatorname{MaxPropCtx}(\smile_D)=6.
\]

## Interpretation rule

If the count differences obtain, the result is a restricted underdetermination theorem:

> The existing verbal aware-ground core does not yet determine the formal compatibility relation that IAR needs. IAR can be adopted as a core formalisation or independently argued for, but it is not currently a derivation.

This is not an argument against aware ground, nondual appearance, or conditional plenitude. It distinguishes their metaphysical interpretation from the missing formal grammar of mode membership.
