# AP3M Immanent-Horizon Structure Test v1: Executed Result

## Question

Can immanent reflexivity, non-objectification, and finite horizon become genuine formal discriminators once the simple compatibility graph is replaced by an explicitly typed self-presentation structure?

## Enriched language

Each grammar family was lifted to
\[
\mathfrak P=(S,\mathcal C,\mathsf{SP},\mathsf H,\mathsf N),
\]
where:

- \(\mathsf{SP}(C)\) is a type predicate saying that \(C\) is self-presenting, not a second observer or content-object;
- \(\mathsf H(C)=S\setminus C\) is the finite mode’s horizon; and
- \(\mathsf N(C,D)\) records distinct contexts with nonempty proper overlap.

The test imposed:

\[
\mathsf H(C)\neq\varnothing,
\]

and required every context to have at least one distinct proper-overlap neighbour. Contexts were evaluated modulo graph automorphisms.

All checks passed.

## Result

The enriched language is necessary for correct statement of the core constraints, but it does not select a topology:

\[
5\ \text{structural families}
\quad\longrightarrow\quad
5\ \text{structural families}.
\]

This is not a null result. It establishes exactly where the logical work lies.

- **Immanence** is a type discipline: self-presence is not produced by a second internal observer.
- **Non-objectification** is likewise a type discipline: the mode is not an object represented to a distinct subject.
- **Finite horizon** constrains every mode to be proper and partial.
- **Real boundary** is handled by quotienting relabellings, not by demanding a unique numerical label.

None supplies a topology discriminator in this language.

## Anti-bias conclusion

It would now be confirmation bias to add a condition solely because it preserves the IAR-like diamond. The test explicitly retains alternative families that satisfy the same core-derived typing.

A stronger constraint is admissible only if it has independent warrant—for example, a richer account of retentional continuity, record closure, agency, or phenomenological organisation—and would remain defensible if it excluded IAR.

## Programme consequence

The core currently fixes the grammar **up to a five-family structural class**. That is a genuine result.

The next formal development, if pursued, must introduce a richer independently justified structure—most naturally an internally ordered retentional/record relation for finite modes—rather than another static compatibility condition. Such an addition must remain internal to finite appearance and must not introduce a background physical time or masquerade as a Problem-of-Time solution.
