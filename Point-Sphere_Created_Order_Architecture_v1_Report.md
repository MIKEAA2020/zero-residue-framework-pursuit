# C1 Created-Order Architecture v1: Executed Sanity Check

## Scope

This report advances C1 under the adopted hard-core + belt programme. It assumes real dependent creation and specifies the common target that all live realization candidates must support. It does not reopen the hard core, prove ontological dependence, solve consciousness, establish libertarian freedom, or solve theodicy.

## Architecture retained

The created order is typed as a structural causal model with internal temporal/causal succession, finite state variables, finite perspectives/access maps, and valence variables. The ground–creation relation \(\mathsf{Dep}_E\) is typed separately as ontological dependence rather than entered as a physical node or competing efficient cause.

This makes six constraints explicit:

1. asymmetric dependence;
2. time internal to creation;
3. differentiated finite/public structure;
4. genuine finite causal action;
5. located finite ignorance; and
6. ethical non-nullity of negative valence.

## Finite sanity check

The toy SCM has one public state, two noisy finite observation channels, two registered finite action variables, local memory/access states, and negative valence when the specified public condition obtains.

| Check | Result |
|---|---|
| Adding only the \(\mathsf{Dep}_E\) metadata leaves every created transition unchanged | Pass |
| Intervention on first finite action changes later public state | 100% of contexts |
| Intervention on second finite action changes later public state | 100% of contexts |
| A local access value is compatible with more than one public state | Pass |
| Both agreement and disagreement between access channels occur for each public state | Pass |
| Negative valence remains represented | Pass |

The check establishes only internal architectural coherence for this toy. It demonstrates how non-competitive ontological-dependence typing can preserve ordinary created causal roles, partial knowledge, public error-correction, and ethical salience. It does not establish that the dependence relation exists or that the ground’s goodness has an adequate permission structure.
