# AP3P2I Uninterpreted-Valuation-Fibre Gauge Audit v1
## Can full lift gauge follow from the existing no-hidden-content discipline?

## New relation type

The prior derivation family asked whether grounding, self-presentation, overlap, or retention determines a Q-coordinate quotient. This audit instead asks a semantic-typing question:

> Does the bare use of the binary code \(\mathbb Z_2\) in AP3G supply intrinsic equality/XOR relations across distinct valuation fibres?

The standing programme discipline prohibits silently importing truth/error semantics, a decoder, external witness structure, or other undeclared content. Apply that discipline to valuation coordinates:
\[
\mathsf{NCC}:\quad
\text{an auxiliary coordinate code contributes no intrinsic relation unless the finite self-presentation grammar explicitly represents that relation.}
\]

NCC is not the claim that local Q values are unreal. Each Q fibre still has two distinguishable local alternatives. It denies only an unrepresented global identification of their coordinate labels across fibres or phases.

## Minimal typed valuation signature

For each trace sector \(s=(a,b)\), use a P fibre \(F^P_s\) and Q fibre \(F^Q_s\), each a two-element local torsor. The declared signature contains:

- phase type P/Q;
- trace sector \(s\);
- local two-alternative fibre membership;
- AP3G local constraints;
- the successor pairing/phase graph.

It contains no declared operation:
\[
F^P_s\times F^Q_s\to\mathbb Z_2,
\qquad
F^Q_s\times F^Q_t\to\mathbb Z_2,
\]
that could realize \(J_s=c\oplus d\) or \(I_{s,t}=d_s\oplus d_t\) as self-presentation content.

## Isomorphism theorem

Write a lift as \(\beta_f\), \(f:S\to\mathbb Z_2\). For any \(h:S\to\mathbb Z_2\), the Q-fibre translation:
\[
\Phi_h:\quad
P(s,c)\mapsto P(s,c),
\qquad Q(s,d)\mapsto Q(s,d\oplus h(s))
\]
maps the successor graph of \(\beta_f\) to that of \(\beta_{f+h}\) and preserves every relation in the minimal typed signature.

Under structural identity for declared self-presentation structure:
\[
\mathsf{NCC}+\mathsf{SI}_{\rm decl}
\Longrightarrow
\beta_f\sim_{\rm desc}\beta_{f+h}.
\]
The full group is transitive, hence one lift class.

## Scope and rival extension

This establishes full gauge **for the minimal AP3P2 grammar read with uninterpreted local valuation fibres**. It does not prohibit a richer grammar from adding a genuine P/Q comparator, cross-sector relation, truth semantics, or other content. Such an addition must be explicit; it cannot be inferred merely from the shared mathematical code \(\mathbb Z_2\).

## Tests

1. The 16 lifts are isomorphic under Q-fibre translations in the declared minimal signature.
2. \(J_s\) and \(I_{s,t}\) change under translations and so are not observables in that signature.
3. Adding either comparator changes the signature and blocks the quotient; it is a new grammar extension, not an already-present AP3G fact.
4. The conclusion is no arbitrary canonical-lift choice, no physical gauge claim, and no claim that enriched relational aspects are impossible.
