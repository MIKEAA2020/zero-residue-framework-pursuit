# AP4C3E1 Mode-History Gauge Audit v1 — Report
## Result: ego-decentering motivates a persistence-gauge theory, but existing formal resources do not supply one

## Question

The ego-decentering proposal distinguishes a mode-local persistence story from a more objective, relationally or invariantly grounded account. The relevant mathematical question is:
\[
\Gamma_{\rm pers}\curvearrowright\mathcal H
\quad\text{and}\quad
\mathcal I(\mathcal H/\Gamma_{\rm pers})\;?
\]

Does the existing programme already contain a declared gauge action on mode histories/transition structures and invariant continuation facts?

## Existing formal resources are not interchangeable

| Resource | What it acts on | Does it identify AP3 contexts as one persisting mode? |
|---|---|---:|
| AP3G \(K=\mathbb Z_2\) | Redundant description label \(u\) in \([C,\nu,u]_K\) | no: it leaves \(C\) and \(\nu\) fixed |
| AP3L \(S_4\) quotient | Labelled grammar descriptions during structural-family classification | no: it is not declared as an in-model mode gauge |
| Compatibility-graph automorphism | Contents/contexts of one unvalued graph skeleton | not yet: it is a candidate structural symmetry, not a declared gauge |
| AP3N \(\prec_C\) | Internal static retentional order of one context | no: it gives no action on transitions/histories |

This separation is decisive. A structural automorphism cannot be silently recast as a gauge of mode persistence.

## Computed graph-symmetry record

| Family | Graph automorphism-group order | Context orbits if graph automorphisms were declared gauge |
|---|---:|---|
| Star of pairs | 6 | one orbit containing all 3 contexts |
| Path-type pairs | 2 | one singleton orbit and one 2-context orbit |
| Pair plus triple | 2 | two singleton orbits |
| Four-cycle of pairs | 8 | one orbit containing all 4 contexts |
| IAR-like overlapping triples | 4 | one orbit containing both triple contexts |

For IAR-like contexts:
\[
C=\{0,1,2\},\qquad D=\{0,1,3\},
\]
the unvalued compatibility graph has an automorphism exchanging contents \(2\) and \(3\), hence mapping \(C\) to \(D\). But AP3G’s actual description gauge does not do this.

If graph automorphism orbits were simply declared gauge, then the AP3L star, cycle, and IAR-like families would collapse several previously distinct maximal contexts into one mode-equivalence class. That might be a defensible retyping under a new theory, but it would revise—not derive from—the AP3G membership rule, where context and valuation belong to mode identity.

## Persistence underdetermination remains explicit

The same static IAR data give incompatible continuation verdicts:

| Candidate rule for \(C,D\) | Verdict |
|---|---:|
| Exact context identity | different/replacement |
| Common coherent ordered trace \(0\prec1\) | continuation |
| Isomorphic internal retentional order | continuation |
| Same untyped graph-automorphism orbit | continuation |
| Same AP3G \(\mathbb Z_2\)-gauge orbit | different/replacement |

No current programme element selects one rule. In particular, the AP4C1 \(S_3\) witness-name gauge concerns redundant record witnesses; it does not act on \(C,D\), their persistence stories, or their trace values.

## Corrected ego-decentering conclusion

The physical analogy supports a useful methodological constraint:

> A mode’s own local persistence narrative should not be promoted to a globally authoritative description merely because it is locally given.

But this does not entail that all persistence narratives are gauge artifacts, or that no invariant persistence fact exists. The framework first needs a specified history/transition domain, a declared distinction between gauge and substantive symmetries, and an invariant observable or law selecting the relevant relational facts.

## Conclusion

AP4C3E1 is a genuine negative/clarificatory result:
\[
\text{existing AP3G/AP3L/AP3N data}
\not\models
\Gamma_{\rm pers}\curvearrowright\mathcal H
\text{ or a persistence invariant}.
\]

The ego-decentering insight now has an exact status. It motivates an additional formal bridge—**a gauge-relative mode-history theory**—but does not dissolve the persistence/error debt, turn graph automorphism into gauge by itself, or reclassify AP4C1’s witness gauge as a gauge of persistence stories.

The next advance requires an explicit non-temporal mode-history structure, a declared gauge/physical-symmetry status for its transformations, and a boundary-preserving invariant persistence criterion. Without this, AP4C1 stays a conditional record-code law and AP3 finite contexts remain distinct modes under their present typing.
