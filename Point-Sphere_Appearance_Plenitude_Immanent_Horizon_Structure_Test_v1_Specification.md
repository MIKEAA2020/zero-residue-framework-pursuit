# AP3M Immanent-Horizon Structure Test v1
## Enrich the grammar language without smuggling in a preferred topology

## Purpose

AP3L showed that the core constraints reduce the finite grammar class to five structural families, while immanence and non-objectification were only informal typing constraints in a plain compatibility graph. AP3M introduces an explicit two-sorted language in which they are represented, then checks whether this representation itself discriminates among the five families.

## Self-presentation structure

For a vocabulary \(S\) and a family of maximal proper contexts \(\mathcal C\), define an enriched structure
\[
\mathfrak P=(S,\mathcal C,\mathsf{SP},\mathsf H,\mathsf N).
\]

- \(\mathsf{SP}(C)\) is a **type predicate**: context \(C\) is self-presenting. It is not a content vertex, a second observer, or a representation of \(C\).
- \(\mathsf H(C)=S\setminus C\) is the finite mode’s horizon.
- \(\mathsf N(C,D)\) holds when \(C\) and \(D\) are distinct contexts with nonempty proper overlap: \(\varnothing\neq C\cap D\neq C,D\).

## Constraints

| ID | Formal condition | Core/route warrant |
|---|---|---|
| I1 | \(\mathsf{SP}(C)\) is typed on \(C\), never represented by a second context or a content in \(S\) | Immanent identity, not higher-order representation |
| I2 | \(\mathsf H(C)\neq\varnothing\) for every \(C\) | Finite determination/partiality |
| I3 | Every \(C\) has a distinct neighbor \(D\) with \(\mathsf N(C,D)\) | Mild phenomenological horizon/contact condition; not claimed as a unique core theorem |
| I4 | Context identity is considered modulo vocabulary automorphisms | Real nonconventional boundary/gauge condition |

I1 and the non-objectifying clause are syntactic/type restrictions. They prohibit an incorrect formulation but may not decide a topology.

## Frozen input

Use the five structural grammar families surviving AP3L. For each, calculate proper horizons and neighbor relations. All five must be evaluated under the same I1–I4 rules.

## Interpretation rule

- If one or more families fail a condition, the condition narrows the grammar class.
- If all survive, the result demonstrates that an immanent/non-objectifying/horizonal language is necessary for correct typing but not sufficient to choose a grammar.
- No additional condition may be inserted merely to preserve IAR; the IAR-blindness test remains active.
