# AP3F Genuine-Mode Membership Audit v1
## Does the present framework contain a noncircular law for \(\operatorname{GenuineMode}\)?

## Purpose

AP3E corrected the unique-selector mistake. Conditional plenitude can non-exclusively realise every genuine mode; it need not choose one candidate perspective over others.

That shifts, but does not remove, the crucial question:

\[
\mathsf M(X,\mathcal R,\mu)
\subseteq
\mathsf{Cand}(X,\mathcal R,\mu).
\]

What determines the subset of candidate restrictions that are genuine modes, rather than merely convenient decompositions of a model?

This audit examines only resources presently present in the Point–Sphere framework. It does not invent a law by renaming a metaphor.

## Acceptance conditions for a membership law

A candidate \(\mathsf M\) is usable only if it passes all seven conditions.

| ID | Condition | Required content |
|---|---|---|
| M1 | Declared domain | State exactly what mathematical/physical objects may be modes: e.g. equivalence classes of restrictions, record algebras, histories, or aspects |
| M2 | Gauge status | Prove that gauge/descriptive copies are not multiplied; state which transformations preserve membership |
| M3 | Nontrivial membership | Include some candidates and exclude others by a stated rule, rather than accepting all formal subsets |
| M4 | Noncircularity | Do not define “genuine” as “conscious,” “actual,” or “the one selected”; do not assume the result in the membership predicate |
| M5 | Nonexclusive coexistence | Permit multiple compatible qualified modes; incompatibility must be explicit rather than assumed from numerical distinctness |
| M6 | Phenomenality typing | State whether membership is only pre-phenomenal or includes self-presentation/phenomenality, and identify the bridge |
| M7 | External/physical linkage | If the law is meant to reach public physics, state records, locality, observables, or dynamics and an eventual discriminating consequence |

## Result

No current component passes M1–M7.

The strongest surviving conditional statement is:

\[
\operatorname{GenuineMode}(m)
\land
\operatorname{AwareGround}(G)
\quad\Longrightarrow\quad
\operatorname{SelfPresent}_G(m),
\]

if self-presentation is taken as integral to the intended nondual identity analysis. Conditional plenitude then gives:

\[
\forall m\,[\operatorname{GenuineMode}(m)\Rightarrow R(m)].
\]

Neither statement provides the missing antecedent \(\operatorname{GenuineMode}(m)\).

This is not a refutation of the aware-ground architecture. It identifies its next irreducible formal/physical commitment. Plenitude governs **realisation of qualified modes**; it does not tell us what qualifies.

## Four possible continuations

1. **Physical closure law.** Define modes through gauge-invariant record/locality/interaction closure in a concrete physical theory. This is potentially public and testable but must not assume a preferred factorisation or time parameter.
2. **Dynamical stability/integration law.** Define modes through a covariant stability or causal-integration functional. It must specify units, threshold status, gauge invariance, and why it avoids AP3D proliferation.
3. **Intrinsic-aspect relation.** State a formal relation between ground-aspect self-presentation and a class of structured modes. This is closest to the core but presently lacks a mathematical object and discriminator.
4. **Protected modal postulate.** Explicitly postulate a genuine-mode membership rule. This allows downstream consequence work but must be acknowledged as a core commitment, not a derivation.

## Verdict and gate

AP3F finds no existing membership law. Further toy partitioning is suspended.

AP3G can begin only after one of the four continuation types is explicitly supplied with its domain, transformation/gauge status, inclusion/exclusion rule, coexistence rule, phenomenality status, and—if physics-facing—recovery/discrimination target.

No current result establishes subjects, conscious fields, personal identity, public physical records, Born weights, spacetime, or a solution to the Problem of Time.
