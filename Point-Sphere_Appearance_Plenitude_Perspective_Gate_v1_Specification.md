# AP3B Perspective Gate v1
## From bounded restriction to genuine mode/perspective: a failure-sensitive criterion

## Purpose

AP3A showed that bounded, non-independent restriction profiles are formally coherent. It did not show that a restriction is a genuine mode, subject, or phenomenal perspective. AP3B makes the missing conditions explicit and applies them to AP3A’s frozen uniform finite model.

## Candidate criterion

Let \((X,\mu,\mathcal R)\) be a global formal aspect model, where \(\mu\) is a state/measure and \(\mathcal R\) supplies declared relational/constraint structure. A candidate local carrier \(V_i\) with public interface \(O_i\subset V_i\) can count as a **pre-phenomenal mode candidate** only if all of the following hold.

1. **Structural individuation:** \(V_i\) is not merely a label-permuted duplicate of another carrier relative to \(\mathcal R\).
2. **Bounded access:** the restriction \(\pi_i:X\to X_{V_i}\) has non-singleton fibres.
3. **Public compatibility:** local profiles satisfy specified overlap/record gluing maps.
4. **Global non-independence:** compatible local profiles have a global amalgamation; no local profile is introduced as a second complete state.
5. **Integrated local content:** at a minimum, the exclusive local content must not factor from the rest of the carrier:
\[
I_\mu\bigl(X_{V_i\setminus O_i};X_{O_i}\bigr)>0.
\tag{Int}
\]
This is a necessary but not sufficient proxy for a unified local mode. A successor may replace it with a stronger constraint/causal integration condition, but may not drop integration entirely.
6. **Boundary condition:** the exclusive contents of distinct profiles must be conditionally screened by their public interface,
\[
I_\mu\bigl(X_{V_P\setminus O};X_{V_Q\setminus O}\mid X_O\bigr)=0,
\tag{Bnd}
\]
or a stated alternative physical boundary law. This prohibits counting arbitrary overlapping fragments as independent modes.

A **phenomenal perspective** requires one additional conditional bridge:

\[
\operatorname{Phen}(i)
\Longleftrightarrow
\operatorname{Mode}(i)
\land
\operatorname{SelfPresent}_G(i).
\tag{Phen}
\]

Within the aware-ground hypothesis, \(\operatorname{SelfPresent}_G(i)\) is intended to mean that the integrated mode is a non-representational self-presentation of the ground. It is not inferred from an information partition. This is a conditional metaphysical bridge, not an established consciousness theorem.

## AP3A evaluation target

AP3A used the uniform measure on
\[
X=\{0,1\}^6,
\]
with \(O=\{0,1,2,3\}\), P-exclusive coordinate \(4\), and Q-exclusive coordinate \(5\).

The frozen AP3B test computes:

\[
I(X_4;X_O),\qquad I(X_5;X_O),\qquad I(X_4;X_5\mid X_O).
\]

## Registered outcomes

- Structural individuation, bounded access, public compatibility, and global amalgamation should pass because AP3A already established them.
- Both integration quantities should be exactly zero under the uniform product state, so AP3A must fail the necessary integrated-local-content gate.
- The boundary conditional mutual information should be zero.
- Phenomenality must remain **undetermined**, not inferred.

## Interpretation rule

If the registered outcome obtains, AP3A is correctly classified as a pre-phenomenal structural compatibility result and cannot be promoted to a perspective/subject result. AP3C must construct a non-arbitrary correlated/constraint-governed model in which integration, boundary, and global non-independence jointly hold, then separately confront the self-presentation/phenomenality bridge.
