# Intrinsic Flow Grammar Postulate — Adoption v1
## AP3P1 adopted as a labelled revisable belt grammar after bounded derivational closure

## Decision

Adopt AP3P1 as the active **Intrinsic Flow Grammar Postulate** for downstream conditional work:
\[
\mathsf{IFG}_{\rm P1}.
\]

This is a Lakatosian belt decision, not a claim that directed intrinsic flow has been derived from the protected core, the aware-ground package, phenomenology, horizon structure, or a physical theory.

## Postulate content

For each valuation-labelled candidate component \(\theta\), posit a phase domain:
\[
P_{\Phi,\theta}=\{p_{n,\theta}:n\in\mathbb Z\},
\qquad
p_{n,\theta}\rightsquigarrow p_{n+1,\theta}.
\]

The branch uses:

1. finite alternating IAR-like phase contexts \(C_P\), \(C_Q\);
2. an ordered two-content retentional trace shared by each adjacent phase pair;
3. a bi-infinite, nonterminal, nonrecurrent intrinsic successor order;
4. a declared phase-origin/P–Q-alternation description gauge;
5. connected successor components as **grammar-level finite mode-flows**;
6. under the minimal local-fibre semantic reading, one connected lift-isomorphism description class for the 16 trace-preserving valuation lift encodings.

## Status and cost

\[
\mathsf{IFG}_{\rm P1}
\not\in
\text{protected core}.
\]

It is a revisable grammar postulate with these explicit costs:

- finite self-presentation has not been shown to entail directed successor flow;
- bi-infinite order, continuation, phase-origin gauge, and component-to-grammar-mode identity are stipulated together in this branch;
- the minimal lift quotient is a description result conditional on the local-fibre/no-hidden-coordinate-content reading, not a prohibition on richer grammars;
- no external physical time, public objectivity, consciousness theorem, QM/GR bridge, probability rule, or ethical conclusion follows.

The postulate does not say that no other finite self-presentation grammar exists. It supplies one active conditional branch for consequences research.

## Bounded derivation closure

The following routes have been tested at their stated strength and do not derive directed successor flow:

- ground/appearance unity;
- reflexive mode unity;
- trace exhaustion and retentional closure;
- finite horizon and clarity gradient;
- static retentional order;
- self-presentation as temporal act absent a finite-temporalization and act-integration theorem.

A lack-directedness route is not opened as a seventeenth reformulation. If lack is defined atemporally, directedness does not give succession; if it is defined through “not-yet,” succession is already assumed. It adds no independently specified relation capable of filling AP3O’s gap.

This is an expiry decision for the present derivation family, not a proof that no future independently warranted theorem is possible.

## Revision conditions

Reopen or revise \(\mathsf{IFG}_{\rm P1}\) only upon one of the following:

1. a noncircular theorem deriving a directed act-integration/successor relation from independently stated finite self-presentation conditions;
2. an independently warranted grammar enrichment incompatible with the P1 phase/successor or minimal-fibre quotient structure;
3. a concrete physical postulate/model that establishes a distinct recoverable physical implementation.

## Downstream use rule

All downstream results must state their antecedent explicitly:
\[
\mathsf{IFG}_{\rm P1}\quad(+\text{ any further stated belt law})
\Longrightarrow\quad\text{conditional result}.
\]

They must not back-propagate the postulate as a derivation of the core or a solution to a physical, ethical, or phenomenological problem.
