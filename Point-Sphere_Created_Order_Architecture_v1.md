# Created-Order Architecture v1
## C1 under the active hard-core + belt programme

## Scope box

**Hard core assumed:** one simple, complete, fully aware, good, unchanging ground; real dependent creation; temporal order internal to creation.

**Belt task:** specify a common architecture in which differentiated finite creation can be temporally ordered, publicly structured, causally active, epistemically partial, and ethically non-null while depending asymmetrically on the ground.

**Does not do:** reopen whether creation is real; derive the hard core; solve the realization-rule contest; prove phenomenality; solve theodicy; or derive physics.

---

## 1. Typed two-layer architecture

For any totality \(T\) delivered by a live realization candidate, define a created-order model
\[
\mathfrak C_T=(\mathcal E,\mathcal T,\mathcal X,\mathcal U,\mathcal F,\mathcal P,\mathcal K,\mathcal V).
\]

- \(\mathcal E\): created events or states;
- \(\mathcal T\): an internal temporal/causal ordering relation, with no ambient time attributed to the ground;
- \(\mathcal X\): finite state variables;
- \(\mathcal U\): created exogenous/noise variables;
- \(\mathcal F\): created structural transition equations;
- \(\mathcal P\): perspective carriers/locations, each associated with access and action variables;
- \(\mathcal K\): perspective-relative epistemic states or access maps; and
- \(\mathcal V\): finite valence/welfare variables.

The ground–creation relation is represented separately:
\[
\mathsf{Dep}_E(\mathfrak C_T).
\]
It is an ontological dependence/sustenance relation, not an extra node, force, time-indexed variable, or competing efficient cause in \(\mathcal F\).

This is a typed commitment. It does not by itself explain how \(\mathsf{Dep}_E\) obtains; it makes clear what a future account must preserve.

---

## 2. Core architectural constraints

### C1-A — asymmetric ontological dependence

Every created state/event exists dependently on \(E\), while \(E\) is not a variable in the created causal model. A theory that makes the ground merely one physical cause beside finite causes violates the architecture; a theory that removes created causal powers violates real creation.

### C1-B — internal time

Temporal succession is an order among created events/states, not a process occurring in a prior time in which the ground changes. The architecture allows a beginning, bounce, cyclic order, or other physical temporal structure; it does not select cosmology.

### C1-C — finite differentiation and public structure

Created variables have non-identical causal roles, and multiple perspectives can track common created variables through distinct access channels. Publicity means overlap and error-correctability of access, not an omniscient created observer.

### C1-D — genuine finite agency

Finite agents may be represented by variables whose interventions alter later created states according to \(\mathcal F\). Their causal efficacy is neither removed by dependence on \(E\) nor elevated to independence from \(E\). Questions of libertarian freedom, responsibility, and permission require additional belt principles.

### C1-E — located ignorance

For any finite perspective \(p\), an access map
\[
\kappa_p:\mathcal E\longrightarrow\mathcal K_p
\]
is partial, coarse-grained, noisy, or history-limited. Ignorance is thereby an architecture-level constraint on a finite perspective, not a contradiction in the ground’s assumed complete awareness.

### C1-F — ethical non-nullity

A negative valence variable is not erased by dependence, common sourcehood, or ontological unity. Any good-ground/theodical proposal must add a separate permission structure; it cannot set \(\mathcal V\) aside by definition.

---

## 3. Conservative causal extension principle

Let \(\mathcal M_T=(\mathcal X,\mathcal U,\mathcal F,P(\mathcal U))\) be a created structural causal model. Add \(\mathsf{Dep}_E(\mathfrak C_T)\) only as a typed ontological relation and do not add a created variable, arrow, or equation to \(\mathcal M_T\). Then every interventional distribution internal to \(\mathcal M_T\) is unchanged.

This principle protects ordinary causal explanation from competition with the ground relation. It is not a proof that ontological dependence exists, and it cannot settle whether a substantive concurrence account is coherent. It merely states the non-competitive target any such account must meet.

## 4. Common compatibility with realization candidates

| Candidate | Created-order use of \(\mathfrak C_T\) | Additional issue |
|---|---|---|
| C-Nec-D | One \(T\) instantiates one \(\mathfrak C_T\) | The determination bridge must fix the architecture/laws without hidden parameters |
| C-Nec-O | Each substantive orbit member has a corresponding \(\mathfrak C_{gT}\) | Need criteria for which differences are genuine and for cross-orbit probability/measure |
| C-Cont | The selected \(T\) instantiates \(\mathfrak C_T\) | The selector must explain why this architecture is selected without arbitrariness/collapse |

Thus C1 supplies a common target architecture; it does not pick a realization rule.

## 5. Frozen finite architecture check

`point_sphere_created_order_architecture_v1.py` implements a finite toy created SCM with:

- one public world state accessible through two separate noisy/partial observation channels;
- two action variables, one of which has a registered causal intervention effect on a future public state;
- separate finite memory/access variables; and
- a negative valence variable under a specified public condition.

The check verifies that adding the ontological-dependence label changes no created causal/interventional distribution, that finite access is non-omniscient, that an action has an internal causal role, and that negative valence remains represented. It is an architecture sanity check only.

---

## 6. Failure conditions and next tasks

C1 fails as a useful belt architecture if it requires the ground as an ordinary created causal node; makes finite causal agency illusory by stipulation; cannot locate ignorance; cannot represent shared public structure; or nullifies harm by ontological vocabulary.

The next C-layer tasks are:

1. construct richer public-structure/individuation models with nested and overlapping perspectives;
2. compare concurrence, conservation, occasionalist, and strict-ND rival typing against C1-A–F; and
3. formulate a positive non-competitive sustenance/concurrence bridge rather than merely a conservative extension constraint.
