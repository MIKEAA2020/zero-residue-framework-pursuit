# AP3C Correlated Mode Test v1
## Minimum integrated, bounded, publicly compatible mode candidates

## Purpose

AP3B correctly rejected AP3A’s uniform-product restriction profiles as unintegrated. AP3C tests whether a nontrivial global constraint support can satisfy the AP3B minimum mode gate without reintroducing independent local substances.

It remains a finite relational/information-theoretic diagnostic. It is not an awareness model, a consciousness measure, a physical theory, or a representation of the simple ground.

## Frozen global support

Use eight relational positions
\[
V=\{0,1,2,3,4,5,6,7\},
\]
with global binary states restricted to
\[
X=\{(o_0,o_1,o_2,o_3,\;o_0,e,\;o_1,f):o_j,e,f\in\{0,1\}\}.
\]
The uniform measure on this support has 64 states. Positions 4 and 6 are respectively constrained public-linked signals \(o_0\) and \(o_1\); positions 5 and 7 carry local variations \(e\) and \(f\).

The fixed relational graph has edges
\[
E=\{(0,4),(0,6),(1,2),(1,7),(2,5),(3,6),(5,6)\}.
\]

Define carriers and public overlap:
\[
V_P=\{0,1,2,3,4,5\},\quad
V_Q=\{0,1,2,3,6,7\},\quad
O=\{0,1,2,3\}.
\]

## Frozen minimum mode gate

For each of P and Q, register all of the following.

1. **Relational individuation:** global graph is rigid and induced P/Q carrier graphs are nonisomorphic.
2. **Bounded access:** each local restriction has non-singleton fibres over \(X\).
3. **Public compatibility and unique amalgamation:** local states agree on \(O\) iff they have exactly one global amalgamation.
4. **Integrated local content:**
\[
I(X_{\{4,5\}};X_O)>0,
\qquad
I(X_{\{6,7\}};X_O)>0.
\]
5. **Boundary screening:**
\[
I(X_{\{4,5\}};X_{\{6,7\}}\mid X_O)=0.
\]
6. **Dual-role local content:** within each exclusive pair, one coordinate is fixed by the public overlap and the other varies at fixed overlap. This prevents counting a wholly redundant public copy or a wholly unintegrated private bit as the candidate by itself.

Passing all six establishes only a **minimum correlated mode candidate**. The phenomenality bridge
\[
\operatorname{Phen}(i)\Longleftrightarrow
\operatorname{Mode}(i)\land\operatorname{SelfPresent}_G(i)
\]
remains conditional and untested.

## Interpretation rule

A pass demonstrates that bounded local profiles can have genuine internal global-local integration while being conditionally independent from one another across a public interface and jointly determined by a single global support. It does not derive the carrier choice, solve the general boundary problem, or establish conscious subjects.
