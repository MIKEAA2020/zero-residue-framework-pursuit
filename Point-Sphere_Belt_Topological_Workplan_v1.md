# Point–Sphere Belt Workplan v1
## Dependency-ordered execution after adoption of the Lakatosian programme

## Rule for interpreting the order

“Earlier” means that a later task depends on its output or needs its failure mode understood. It does not mean that the hard core has been proved, or that a later task is unimportant.

| Rank | Node | Why it comes here | Current executable next action |
|---:|---|---|---|
| 1 | B-C1: synthetic carrier robustness | It is already implemented at fixed seed and directly tests whether locked operational criteria recover encoded answers | Run the frozen seed/sample/coupling/size grid without changing blind-pipeline rules |
| 2 | B-F1: interacting-field calibration | The action and samplers exist, but production depends on a reproducible mass-tuning gate | Freeze pooled-moment, chain-replicated tuning and cross-sampler validation |
| 3 | B-R1: realization-rule formal comparison | It needs the hard-core/belt typing but not empirical data | Define C-Nec-D/C-Nec-O/C-Cont model classes, primitive costs, and exact discriminators |
| 4 | B-C2: graph estimation and hidden-global nulls | Depends on understanding the ideal-graph robustness result | Add estimated-graph, latent/common-mode, multi-interface, and overlap stress families |
| 5 | B-M1: measure proposal | Requires a formal realization proposal rather than generic plenitude rhetoric | Specify an admissible space, invariance group, candidate measure, and non-post-hoc test |
| 6 | B-F2: five-size interacting production | Depends on B-F1 tuning validation | Run the frozen \(N\in\{16,24,32,48,64\}\) programme and report all failures |
| 7 | B-P: psychophysical bridge | Depends on successful B-C gates and proper interventions | Tier-1 calibration, then only a held-out Tier-2 comparison |
| 8 | B-E: ethical/theodical extension | Requires an explicit source-agency and permission model | Compare concrete models under fixed suffering constraints |

## Current decision

B-C1 is both the highest unblocked and the most feasible current node. The next artifact is therefore a frozen robustness/count-recovery grid for the existing nonlinear v2 generator and blind v1 pipeline. Its result will not be allowed to change the hard core, thresholds, candidate budget, or answer key.
