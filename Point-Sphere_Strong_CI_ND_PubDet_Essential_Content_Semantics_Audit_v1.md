# Strong CI Adjudication — ND Public Determination: Essential-Content Semantics Audit v1
## A predeclared attempt to specify genuine aspects without realization or grammar membership

## Status

**This declared candidate semantics expires without a public-domain pass.** It is realization-independent in form, but either undergenerates on a thin core or collapses into protected core membership on a rich core. It does not classify independent finite candidates.

## 1. Predeclared target

The target is a criterion \(\mathsf{PubDet}_G(a)\) for finite candidate \(a\) that does not contain actual realization \(R(a)\), actual modehood, or a synonym for already-admitted aspecthood.

A pass must identify:

1. a positive finite candidate independently of a protected membership declaration;
2. a negative coherent, non-gauge finite candidate;
3. typed inclusion/exclusion semantics;
4. compatibility/compossibility treatment; and
5. an outcome robust against matched rival expansions.

## 2. Predeclared proposal: essential self-knowledge content

Let \(\mathcal M_G\) be the class of interpretations compatible with a stated essence theory \(\mathsf{Ess}_G\), and let \(K_M(a)\) mean that \(a\) is content of \(G\)'s self-knowledge in model \(M\). Define:

\[
\mathsf{EC}_G(a):
\quad
\mathsf{FiniteCandidate}(a)
\land
\mathsf{NonGauge}(a)
\land
\forall M\in\mathcal M_G\;K_M(a).
\tag{EC}
\]

The intended reading is:

> A finite candidate is a genuine aspect if it is an essential, non-duplicate self-knowledge content in every essence-compatible interpretation of \(G\).

\(\mathsf{EC}_G\) contains no realization predicate. It is therefore a legitimate candidate for audit, not an assumed solution.

## 3. Expiry conditions declared before evaluation

EC fails if any of the following occurs:

1. \(\mathsf{Ess}_G\) already lists or entails the exact candidate domain by stipulation;
2. \(\mathcal M_G\) has no independently specified semantics;
3. a coherent, non-gauge independent candidate can be added/removed without violating \(\mathsf{Ess}_G\);
4. no independently identifiable positive/negative pair is generated; or
5. compossibility is silently assumed through one total model.

## 4. Thin-core result

Let \(K_0\) contain only nonrepresentational complete self-knowledge/identity claims while omitting finite articulation. Then there are essence-compatible interpretations with no specified finite candidate contents.

\[
K_0
\not\models
\exists a[
\mathsf{Finite}(a)
\land
\mathsf{EC}_G(a)
].
\]

Thus EC cannot recover finite genuine aspects from thin self-knowledge alone. This is not a criticism of protected \(P_{\rm ND}\), whose core already includes real finite modes.

## 5. Rich-core result

Let rich protected \(P_{\rm ND}\) contain real finite modes/aspects as core content. There are two possibilities.

### A. Exact domain encoded in \(\mathsf{Ess}_G\)

If \(\mathsf{Ess}_G\) specifies the all-and-only finite domain \(D\), EC returns that domain:

\[
\mathsf{EC}_G(a)
\Longleftrightarrow
 a\in D.
\]

But this is not a public semantics for independent candidates. It restates protected core membership in modal language.

### B. Domain not exactly encoded

If \(\mathsf{Ess}_G\) says finite modes are real but does not state exact membership, then an independently described coherent, non-gauge finite candidate \(b\) remains undetermined:

\[
\mathsf{Coh}(b)
\land
\mathsf{NonGauge}(b)
\not\Rightarrow
\forall M\in\mathcal M_G\;K_M(b).
\]

EC supplies no positive classification of \(b\), no principled exclusion, and no public exact domain.

## 6. Positive/negative-case test

| Candidate case | EC outcome | Why it fails the public-pass demand |
|---|---|---|
| A finite mode explicitly protected as core | included conditionally | Its status is supplied by the protected core, not independently classified |
| A coherent non-gauge formal candidate not listed in core | undetermined | EC provides no inclusion/exclusion semantics |
| A syntactic/gauge duplicate | excluded by non-gauge filter | Duplicate removal is not genuine-aspect determination |

No independent positive/negative pair is generated.

## 7. Compossibility and context

Quantifying over one class \(\mathcal M_G\) cannot silently treat all finite candidates as jointly compatible. EC needs an additional context relation:

\[
\mathsf{Comp}_G(a,b)
\quad\text{or}\quad
\mathsf{Ctx}_G(C),
\]

with independent semantics. Adding it produces a further bridge; it does not follow from essential content alone.

## 8. Exact result

\[
\boxed{
\mathsf{EC}_G\ \text{is realization-independent in form but has a thin/rich dilemma:}
}
\]

\[
\boxed{
\text{thin \(\mathsf{Ess}_G\): no finite domain is generated;}
\qquad
\text{rich exact \(\mathsf{Ess}_G\): core membership is restated;}
\qquad
\text{rich inexact \(\mathsf{Ess}_G\): independent candidates are undetermined.}
}
\]

Therefore:

\[
\boxed{
\mathsf{EC}_G
\not\Rightarrow
\mathsf{PubDet}_G.
}
\]

## 9. Consequence

This is a concrete failed attempt, not an impossibility proof. It blocks the route “genuine aspects are simply essential self-knowledge contents” unless an independently articulated essence/domain semantics and compossibility relation are supplied.

No new verbal reformulation of aspecthood is admitted by this audit. Any successor must predeclare a relation type, positive/negative cases, and expiry condition before it is assessed.

## Nonclaims

This audit does not deny protected core finite modes, reject nonrepresentational self-knowledge, prove that no \(\mathsf{PubDet}_G\) can exist, or alter the conditional omission theorem. It tests one precise essential-content proposal and finds no public pass.
