# GA0 — Genuine-Aspect Criterion Typing Audit v1
## Executed type result

## Question

What kind of object can be a genuine finite aspect, and which available conditions are necessary, insufficient, or disallowed as an inclusion criterion?

This audit is the first node of `Point-Sphere_Global_Coherence_Genuine_Aspect_Criterion_Programme_v1.md`. It does not attempt to solve membership by a new formal grammar.

## 1. Required type separation

| Symbol/type | Role | Cannot be identified with |
|---|---|---|
| \(G\) | one non-structural ground | a node, state, manifold, grammar, or domain element |
| \(\omega\in\Omega\) | formal description | a genuine aspect merely by being describable |
| \([\omega]_K\) | gauge-quotiented description class | a genuine aspect merely by being non-gauge |
| \(c\) | finite proper context | an aspect merely by being maximal/coherent |
| \(a\) | candidate finite determination/content | a realized aspect merely by being a candidate |
| \(\mathsf{GA}(a)\) | genuine-aspect predicate | \(R(a)\), a formal-membership bit, a consciousness label, or a privileged grammar class |
| \(R(a)\) | realization | the criterion that makes \(a\) genuine |
| \(\mathcal M\) | a formal grammar/model | ground-level structure or an automatic ontology |

The target is a semantic/metaphysical predicate:

\[
\mathsf{GA}(a)
\equiv
\text{\(a\) is a genuine finite determination of the one reality in self-knowledge.}
\]

This does not imply a second ontological level. “Ground-description” and “finite-aspect description” are descriptions of one reality; the finite determination is not an external object selected or placed into a medium.

## 2. Excluded criteria

The following cannot define genuine aspecthood.

\[
\mathsf{GA}(a)\iff R(a)
\]

is circular because the internal omission theorem derives realization only after genuine aspecthood is given.

\[
\mathsf{GA}(a)\iff\mathsf{Coherent}(a)
\]

is overinclusive: many coherent formal structures need not be determinations of the ground’s nature.

\[
\mathsf{GA}(a)\iff a\in[\omega]_K
\]

is a category error: quotienting removes descriptive redundancy but does not establish semantic target membership.

\[
\mathsf{GA}(a)\iff a\text{ belongs to an IAR-like or other preferred grammar}
\]

silently converts a descriptive belt choice into ontology, violating Revision C.

## 3. Necessary-condition schema

The present resources support only this necessary-condition schema:

\[
\mathsf{GA}(a)
\Rightarrow
\mathsf{Det}_G(a)
\land
\mathsf{Coh}(a)
\land
\mathsf{NG}(a)
\land
\mathsf{Ctx}(a).
\tag{GA-N}
\]

where:

- \(\mathsf{Det}_G(a)\): \(a\) is a finite determination of the one ground’s self-knowledge, not a separate created entity or a formal label;
- \(\mathsf{Coh}(a)\): \(a\) is internally non-contradictory in its declared finite context;
- \(\mathsf{NG}(a)\): \(a\) survives the declared class of purely descriptive/gauge transformations;
- \(\mathsf{Ctx}(a)\): \(a\) belongs to at least one admissible maximal proper context, with incompatibilities typed contextually rather than conjoined in one finite context.

The structural predicates \(\mathsf{Coh},\mathsf{NG},\mathsf{Ctx}\) are necessary filters. They are not sufficient. The non-structural semantic predicate \(\mathsf{Det}_G\) is the remaining load-bearing term.

## 4. Existing results reused

- **AP3F:** no existing executable formal membership law passed the required domain/gauge/nontriviality/noncircularity tests.
- **AP3P2D/E/F/J:** the same typed formal base supports rival aspect typings and gauge choices; common grounding, isomorphism, trace equivalence, and closure do not settle aspect membership.
- **AP3L / AP3I:** maximal proper context architecture constrains finite compatibility, but does not turn all formal contexts into genuine aspects.
- **AP3P3C:** grammar results are appearance-level description results; they require target-relative fidelity before application to modes.

Therefore the current structural resources admit matched expansions with the same formal/gauge/context data but different \(\mathsf{GA}\) extensions. No purely structural membership theorem is available from them.

## 5. GA0 result

The open problem is correctly retyped. It is not a realization-law problem:

\[
\mathsf{GA}(a)
\overset{\text{internal omission theorem}}{\Longrightarrow}
R(a).
\]

It is a semantic determination/fidelity problem:

\[
\text{What makes a finite candidate a determination of the one reality’s self-knowledge?}
\]

GA0 passes as a typing audit and directs GA1/GA2. It does not supply a sufficient aspect criterion.
