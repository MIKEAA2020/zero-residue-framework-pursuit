# AP3K Physical Grammar-Constraint Audit v1
## Can existing physical structure select self-presentation grammar without importing it?

## Purpose

The phenomenological route constrains what finite self-presentation must be like, but does not choose a formal compatibility grammar. AP3K audits whether existing Point–Sphere physics-facing work contains an independent physical condition that could do so.

A usable physical grammar constraint must meet all of:

| ID | Requirement |
|---|---|
| P1 | Declares physical variables, gauge status, state space, and observables |
| P2 | Is invariant under gauge/redescription, rather than selecting a coordinate or label |
| P3 | Does not assume the preferred system/environment, locality, fragment, or perspective factorisation in its premise |
| P4 | Does not require an external background time when intended for fundamental application |
| P5 | Produces stable local/public record structure and states its branch/boundary dependence |
| P6 | Has a recovery/discrimination path relative to known physics |

## Audit

| Candidate physical resource | What it might constrain | Result against P1–P6 |
|---|---|---|
| T1b/T1c relational clocks and pointer records | Which variables are conditionally recorded | **Fails grammar selection:** interactions stipulate the pointer coupling; T1c records a turning variable with substantial backreaction and no global selection result |
| T2 symmetry no-go | Prohibits invariant unique selection within a transitive clock orbit | **Constraint only:** proves no selection from invariant score; does not furnish a mode grammar |
| T3 semiclassical WKB/decoherence | Branch-relative records, approximate conditional dynamics | **Conditional only:** requires state/boundary, branch, system–environment split, and coarse graining |
| T4 branch/decoherence toy | Separation of decoherence from branch orientation | **Negative:** outgoing orientation was imposed in state/boundary data |
| T5 articulation/redundancy diagnostic | Candidate public-record/redundancy condition | **Fails P3:** fragment/environment factorisation is assumed; branch-neutral articulation is orientation-blind and does not define a unique physical mode grammar |
| C2 sensor–memory–action toy | Structural carrier boundaries and public interface | **Pre-physical:** roles, histories, and interventions are stipulated in a finite created-order graph |
| Existing graph-field model | Potential relational dynamics | **Fails P4:** assumes external \(t\), so it is not a fundamental internal-mode law |

## Result

No present physical component meets P1–P6. The most important failure is the same across the candidates:

\[
\text{record/redundancy/locality criterion}
\quad\text{requires a factorisation or interaction structure that already determines candidate modes.}
\]

It cannot then be cited as a derivation of that factorisation or grammar.

This confirms, rather than adds to, the existing T5 and T6 results:

- T5 found that stronger public-record/redundancy claims require a physical locality/factorisation input and an independent time-odd source for orientation.
- T6 found no current Point–Sphere equation, measure, gauge-invariant observable, or selection law that changes the physical Problem-of-Time solution space.

## Correct interpretation

The physical route is not ruled out. It is simply not currently supplied by the framework.

A future physical grammar law would need to specify, in one model:

\[
(\text{state space},\ \text{gauge group},\ \text{local/record algebra},\ \text{dynamics or constraint},\ \text{boundary/measure}),
\]

and prove that its mode contexts are gauge-invariant, non-arbitrary, publicly recordable, and stable in an appropriate recovery regime.

## AP3K verdict

AP3K is a negative audit. It adds no new foundational debt to the aware-ground identity. It shows that current physical work does not yet select a self-presentation grammar independently of preselected factorisation, records, or time. The formal/phenomenological grammar programme remains the active general-framework route.
