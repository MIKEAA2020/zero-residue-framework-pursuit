# Realization-Rule Admissibility Families v1
## R1c; frozen active-belt diagnostic of genuine primitive structure

## Scope box

**Hard core assumed:** one simple, complete, fully aware, good, unchanging ground and real dependent creation.

**Belt task:** identify, in matched finite models, when C-Nec-D, C-Nec-O, or C-Cont adds genuine selection/distinguishing structure rather than only redescribing a chosen outcome.

**Does not do:** prove a metaphysical realization rule, model the intrinsic nature of the ground, decide full plenitude, produce a physical cosmology, or calculate a Born measure.

## Common symmetric admissibility space

Let
\[
\Omega=\{0,1,2,3\},
\]
with full relabelling symmetry \(S_4\). Before an additional bridge is declared, all four toy totalities have identical admissibility status. The diagnostic enumerates the 24 permutations of \(S_4\) and checks invariant realized subsets.

## Frozen matched families

### D0 — bare determinate output

Set \(\mathcal R=\{0\}\), with no distinguishing structure supplied by the common domain. Test whether the singleton is invariant under \(S_4\). It must fail. The result diagnoses that merely naming a unique output is not an equivariant determination from a fully symmetric domain.

### D1 — determinate bridge with marker

Add a marker \(m\in\Omega\) to the determination bridge and set \(\mathcal R_D(m)=\{m\}\). Record that the marker has four possible values (two bits of choice in this finite toy), unless a later theory derives it from structure outside the common symmetric domain.

### O0 — full transitive orbit

Let a specified cyclic \(C_4\) action act transitively. Set \(\mathcal R_O= C_4\cdot0=\Omega\). Verify that this is invariant under its declared action and that the finite uniform measure is normalized. Record separately that the choice of a particular action/group is itself a belt bridge unless independently derived.

### O1 — restricted orbit

Use the subgroup \(H=\{e,(01)(23)\}\) and seed 0, giving \(H\cdot0=\{0,1\}\). Check that it is not invariant under all \(S_4\) relabellings. Record the subgroup/partition and seed as additional structures required to make this a restricted, rather than full, orbit.

### C — contingent selector

Set \(\mathcal R_C(q)=\{q\}\) for \(q\in\Omega\). Verify that varying q changes the realized output while all common-domain structure is held fixed. Record q as a genuine extra primitive in this family unless a positive selector theory is added.

## Interpretation rule

A parameter is called **genuine in the toy** when changing it changes \(\mathcal R\) while the common admissibility space and its declared symmetries are held fixed. This is a formal diagnostic, not an assertion that every metaphysical distinction must be measured in bits or that the hard core lacks internal determination.

## Required outputs

Report: full-symmetry invariance of each realized set; orbit sizes; finite measure normalization; output dependence on markers/selectors; and the declared extra bridges. Do not rank candidates solely by toy primitive counts.
