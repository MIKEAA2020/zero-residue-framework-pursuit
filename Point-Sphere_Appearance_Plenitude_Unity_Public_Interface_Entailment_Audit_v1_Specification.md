# AP4U Unity-to-Public-Interface Entailment Audit v1
## Does the protected unity claim entail AP4A's public-retentional-interface premise?

## Purpose

AP4A established a valid finite conditional discriminator:
\[
\mathsf{PRI}(\mathcal P)
\Longrightarrow
\text{IAR-like grammar}
\]
within the five AP3L families, where every participating context has a distinct context sharing an ordered pair of contents. AP4U tests a narrower upstream issue: whether that antecedent follows from the protected nondual identity plus the claim that modes are determinations of one self-knowledge.

This is an entailment audit, not a revision of the protected core, a new realisation principle, or a claim of physical objectivity. AP4C remains held: it requires an explicit robust record law.

## Locked core and target

The protected identity is:
\[
\mathsf{GenuineMode}(m)
\equiv
\mathsf{SelfAspect}_G(m)
\equiv
\mathsf{ContentOfSelfKnowledge}_G(m).
\tag{K}
\]

The unity supplement under examination says only that every mode is a determination of one ground/self-knowledge \(G\):
\[
\forall C\in\mathcal P\;\mathsf{Of}(C,G).
\tag{U0}
\]

AP4A's public-retentional-interface condition is:
\[
\mathsf{PRI}(\mathcal P):\quad
\forall C\in\mathcal P\;\exists D\in\mathcal P\;(D\ne C)\;\exists x\ne y\in C\cap D:
\quad x\prec_Cy\ \land\ x\prec_Dy.
\tag{PRI}
\]

`\mathcal P` here is the declared set of modes participating in the interface test. This does not assert that every possible finite mode is public.

## Logical questions

The audit separately tests the three proposed steps:

\[
(K+U0)
\stackrel{?}{\Longrightarrow}
\text{shared content},
\qquad
\text{shared content}
\stackrel{?}{\Longrightarrow}
|C\cap D|\ge2,
\qquad
|C\cap D|\ge2
\stackrel{?}{\Longrightarrow}
\text{shared ordered pair}.
\]

The test is failed for an alleged entailment whenever an explicit finite countermodel satisfies its antecedent and fails its consequent.

## Registered countermodels

All examples treat every displayed finite context as a bounded genuine mode/aspect/content of the one \(G\), with no external time coordinate.

1. **AP3L path-pairs survivor:**
   \[
   \{0,1\},\ \{0,2\},\ \{1,3\}.
   \]
   The last two contexts are disjoint. It tests whether common grounding entails overlap.

2. **AP3L star-pairs survivor:**
   \[
   \{0,1\},\ \{0,2\},\ \{0,3\}.
   \]
   Every pair shares \(0\), but no pair shares two contents. It tests whether even universal one-content commonality entails the AP4A cardinality threshold.

3. **Two-common-contents, unordered-trace model:**
   \[
   C_i=\{g_1,g_2,a_i\}\quad(i=1,2,3),
   \qquad
   \prec_{C_i}=\{(g_1,a_i)\}.
   \]
   Every pair shares \(g_1,g_2\); every context has nontrivial endogenous order; the order restrictions agree exactly on overlaps; but \(g_1,g_2\) are incomparable. It tests whether two shared contents plus AP3N-style coherent local order entails a shared ordered pair.

4. **IAR-like positive control:** the AP4A overlapping-triples family, supplied with its AP3N internal-order witness, must satisfy \(\mathsf{PRI}\).

## Bridge classification rule

- **Derived:** \(K+U0\models\mathsf{PRI}\); no additional bridge is used.
- **Bridge needed:** a strictly stronger relation is needed, and is displayed separately.
- **Re-description/circular:** the alleged bridge states that relevant modes already share a two-content coherent retentional trace; it is extensionally the AP4A premise, not its derivation.

The audit does not rule out a future substantive bridge. A candidate bridge must be independently motivated, preserve finite partiality and non-objectification, and survive alternatives such as temporally thick contents, mediated records, or a gauge-invariant relational record algebra.

## Registered conclusion target

The expected conclusion is:
\[
K+U0\not\models\mathsf{PRI}.
\]

Therefore AP4A remains a genuine conditional discriminator. Any move from core unity to public interface must be stated and evaluated as an additional bridge rather than silently absorbed into the word “unity.”
