# G3/CFD Rival Operationalization Packet v1
## Pre-corpus requirements for classical participation, whole-first, and null/deflationary rivals

## Status

**No broad metaphysical rival has yet been operationalized for the restricted phenomenal calibration. This packet specifies what must be supplied before corpus lock. It does not assign predictions on a rival's behalf.**

The point is to prevent a false matched-rival comparison in which a rival is defined only by a label while CFD receives an executable classifier.

## 1. Shared prediction interface

For every valid in-scope calibration item \(d\), a rival must provide before corpus lock:

\[
V_R(d)\in\{+,-,\bot\},
\]

where:

- \(+\) predicts the independently specified local-presentation target;
- \(-\) predicts the independently specified non-field/list-or-no-presentation target;
- \(\bot\) means that the rival makes no prediction at this restricted interface.

The input available to a rival is frozen as:

\[
I(d)=\langle
R^{\rm raw}_{\alpha},
R^{\rm struct}_{\alpha},
\Pi(m),
\text{predeclared neutral metadata}
\rangle.
\]

A rival may not access:

\[
\mathsf{CertField}_{\alpha},
\quad
\mathsf{Core}^{\rm cmp},
\quad
\text{any CFD verdict},
\quad
\text{or post-lock corpus outcomes}.
\]

## 2. Minimum operationalization submission

For \(V_R\) to count as operationalized, its proponent must supply all of:

\[
\langle
D_R,
C_R,
A_R,
X_R,
B_R
\rangle,
\]

where:

1. \(D_R\): a declared restricted phenomenal domain;
2. \(C_R\): a realization-independent criterion expressed on \(I(d)\);
3. \(A_R\): an explicit decision algorithm or finite rule yielding \(+\), \(-\), or \(\bot\);
4. \(X_R\): positive and negative formal examples generated independently of the CFD result; and
5. \(B_R\): a statement of the metaphysical bridge from the formal/phenomenal criterion to the rival's own ontology.

The rival need not accept nondual premises. It must only state what its own theory predicts about the restricted calibration target.

## 3. Prohibited operationalizations

The following do not count:

\[
\begin{array}{ll}
P1 &: \text{“The rival explains whatever the data show.”}\\
P2 &: \text{“Fieldhood is whatever CFD calls fieldhood.”}\\
P3 &: \text{A rule defined after viewing the certified labels or CFD verdicts.}\\
P4 &: \text{A metaphysical label with no input-to-verdict algorithm.}\\
P5 &: \text{A rule whose only difference is verbal renaming of CFD's profile criterion.}
\end{array}
\]

A rival that supplies only \(\bot\) is not thereby false. It is simply non-discriminating in this restricted empirical/phenomenal test.

## 4. Classical participation submission requirements

For a classical participation/creator framework \(R_{\rm part}\), the operationalization must state, without using CFD's graph-unity rule:

\[
\begin{array}{ll}
CP1 &: \text{what counts as a finite phenomenal unity or non-unity};\\
CP2 &: \text{whether unity is grounded in a created substance, form, act, participation, or another relation};\\
CP3 &: \text{how this criterion returns }+,-,\bot\text{ for }I(d);\\
CP4 &: \text{why that rule follows from participation rather than being an added neutral psychology.}
\end{array}
\]

No prediction is assigned here. Classical participation has historically diverse accounts of finite form, soul, unity, and experience; assigning one on its behalf would be a strawman.

## 5. Whole-first submission requirements

For a whole-first account \(R_{\rm whole}\), the operationalization must state:

\[
\begin{array}{ll}
WF1 &: \text{what whole is prior in the restricted phenomenal case};\\
WF2 &: \text{how a local report is tested for belonging to one articulation rather than an aggregate};\\
WF3 &: \text{how the whole-first criterion differs from mere graph connectedness};\\
WF4 &: \text{the }+,-,\bot\text{ algorithm and bridge to whole-first ontology.}
\end{array}
\]

A simple assertion that “every item belongs to the whole” is not a discriminator. It must say which local reports count as one phenomenally unified articulation and why.

## 6. Null/deflationary submission requirements

For a null/deflationary rival \(R_{\rm null}\), there are two admissible routes:

\[
\begin{array}{ll}
N1 &: \text{declare }V_{R_{\rm null}}(d)=\bot\text{ for all }d,\text{ rejecting the target as ontologically loaded};\\
N2 &: \text{give a non-metaphysical report-classification algorithm returning }+\text{ or }-.
\end{array}
\]

Under N1, the rival is a methodological challenge to the entire selector test but not an extension-level empirical competitor. Under N2, it becomes scoreable under the same rules as other rivals.

## 7. Pre-lock adversarial checks

Before any corpus item is classified, each submitted \(V_R\) is tested on a frozen set of synthetic interface cases. These cases test only whether the algorithm is total and non-circular; they are not validation data.

The test set includes:

\[
\begin{array}{ll}
T1 &: \text{one supported complete single-phase profile};\\
T2 &: \text{a complete sequential profile};\\
T3 &: \text{a complete disconnected profile};\\
T4 &: \text{a semantically inconsistent diagram};\\
T5 &: \text{an incomplete report/diagram.}
\end{array}
\]

A rival must produce its verdict and a written rationale for each item before corpus lock. A reply of \(\bot\) is permitted but makes the rival non-discriminating for that interface case.

## 8. Scoring eligibility and expiry

A rival is scoreable only if:

\[
\begin{array}{ll}
E1 &: \text{its full submission passes §§1--3};\\
E2 &: \text{it supplies }+\text{ or }-\text{ on at least 90\% of valid corpus items};\\
E3 &: \text{its rule is frozen before }\mathsf{CertField}\text{ and CFD verdicts are merged};\\
E4 &: \text{it does not use the forbidden inputs in §1.}
\end{array}
\]

If no broad rival is scoreable by:

\[
d_\star=\text{2026-12-31},
\]

the broader-metaphysical matched-rival component is inconclusive. CFD receives no comparative advantage from that absence.

This does not alter the availability of the already frozen formal rivals \(R_{\rm syn}\) and \(R_{\rm atom}\).

## 9. Exact result

\[
\boxed{
\text{The packet makes broad-rival comparison possible only after independently specified rival interfaces are supplied.}
}
\]

\[
\boxed{
\text{No current classical, whole-first, or null/deflationary prediction has been manufactured for them.}
}
\]

## Nonclaims

This packet does not claim that any rival must be empirically discriminable at the restricted phenomenal interface, that a non-predictive rival is false, or that winning a local calibration test identifies the correct framework of reality.
