# AP3P2B Valuation-Lift Gauge-Equivalence Audit v1 — Report
## The 16 lifts form a redefinition torsor, but no existing principle makes that redefinition gauge

## Result

The 16 trace-preserving AP3P2A lifts are not an unstructured list. They form the affine action space:
\[
\mathcal L\cong(\mathbb Z_2)^4.
\]

For a lift \(f\) and a sector-dependent Q-side free-bit redefinition \(h\),
\[
\beta_f(a,b,c)=(a,b,c\oplus f(a,b)),
\]
\[
\eta_h(a,b,d)=(a,b,d\oplus h(a,b)),
\]
and exactly:
\[
\eta_h\circ\beta_f=\beta_{f+h}.
\]

Every \(\eta_h\) preserves:

- the trace values \((r_0,r_1)=(a,b)\);
- the Q constraint \(q_s=r_1\);
- legality of binary Q valuations;
- the alternating AP3P1 phase-flow form.

## Orbit record

| Transformation status | Group | Effect on the 16 lifts |
|---|---|---:|
| Existing AP3G gauge | redundant-label \(\mathbb Z_2\) only | 16 separate lift classes |

| Candidate trace-sector-dependent Q-coordinate redefinitions | \((\mathbb Z_2)^4\) | 1 sixteen-element orbit |

Thus no privileged canonical lift is mathematically necessary **if** the full sector-dependent redefinition group is admitted as a description gauge.

## Why that conditional matters

The full group is not part of AP3G’s actual gauge. AP3G’s \(\mathbb Z_2\) changes only the redundant label \(u\); it leaves valuation values fixed. By contrast, a nontrivial \(\eta_h\) changes the Q-side free content value \(q_v\), potentially in a different way for each shared-trace sector.

Consequently, there are three distinct claims:

1. **Mathematical fact:** all 16 lifts are related by legal trace-preserving coordinate redefinitions.
2. **Possible new formal convention:** one may declare some or all of those redefinitions gauge.
3. **Unestablished stronger claim:** those redefinitions are physically, phenomenologically, or core-metaphysically redundant.

Only the first is established here.

A full declaration of \((\mathbb Z_2)^4\) as gauge would remove the lift-selection debt, but it would be a substantive extension. It would treat sector-conditioned changes in a valuation content currently included in AP3G mode identity as redescription. A uniform-only gauge leaves eight inequivalent classes. Existing resources select neither option.

## Boundary consequence

The field redefinition maps one complete flow-law presentation to another while the P-side \(\theta=(a,b,c)\) labels can remain fixed. Hence it does not automatically collapse the eight declared flow components. But neither does it derive their non-arbitrary individuation. The component rule remains an explicit convention pending a principle about which valuation distinctions are genuine and which are descriptive.

## Conclusion

AP3P2A’s underdetermination has been reduced to an exact choice point:
\[
\text{all lifts equivalent under }H_{\rm full}
\quad\text{iff}\quad
H_{\rm full}\text{ is independently warranted as gauge}.
\]

The task is no longer to search blindly among 16 lifts. It is to justify a gauge status for a redefinition group—or retain multiple inequivalent lift classes as genuine alternatives and compare their consequences. No derivation from the core, public-record result, physical time law, or Problem-of-Time solution follows.
