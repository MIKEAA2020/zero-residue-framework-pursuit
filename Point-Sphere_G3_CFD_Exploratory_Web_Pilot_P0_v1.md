# G3/CFD Exploratory Web Pilot P0 v1
## Feasibility check only: one public DES transcript episode

## Status

**Exploratory coding-feasibility pilot. This is not confirmatory data, not a CFD test, and not a phenomenal-certification exercise. No Core verdict is computed.**

## 1. Source record

- Source family: public Descriptive Experience Sampling (DES) materials
- Source page: `https://hurlburt.faculty.unlv.edu/ieo/sadie/sadie_sampling.html`
- Transcript: `https://hurlburt.faculty.unlv.edu/ieo/sadie/Sadie_interview_1_transcript_with_commentary.pdf`
- Episode examined: Sadie, first sampling-day discussion, sample 1.2
- Source status: archival, framework-external, but ineligible for frozen confirmatory corpus

The transcript itself describes the first sampling day as chiefly iterative training and indicates that DES normally discards first-day descriptions for substantive characterization. That is a source-specific reason not to treat this episode as a high-fidelity calibration item.

## 2. Minimal report-level content

At the target moment, the discussion describes at least:

\[
\text{a localized tongue-pressure/squishing sensation}
\]

and:

\[
\text{the abbreviated word “Thurs” as somehow present, with uncertainty about its exact mode.}
\]

The source also discusses possible simultaneity, salience, and uncertainty. These are descriptive leads, not G3-coded facts.

## 3. G3 coding-manual audit

The frozen G3 manual requires every complete in-scope report to satisfy:

\[
C1\text{--}C6,
\]

including a decided quality-by-phase matrix, phase-order matrix, same/different decisions, satisfiability, and no unreported enrichment.

The archival transcript does not contain the G3 structured completion form. In particular, it does not decide:

\[
\begin{array}{ll}
C2 &: \text{every active }\mathsf{HasAt}(s,q,e)\text{ entry as yes/no};\\
C3 &: \text{all active phase-order entries as yes/no};\\
C4 &: \text{all active equality/disequality claims};\\
C6 &: \text{a unique negative completion without adding unreported material.}
\end{array}
\]

The report contains uncertainty about how the word was present and about some temporal/experiential distinctions. That uncertainty may be phenomenologically valuable, but it may not be silently converted into negative literals.

## 4. Result

The only valid result is:

\[
\boxed{
\mathsf{OutOfScope}_{\rm incomplete}(\text{DES-Sadie-1.2}).
}
\]

The pilot does **not** infer:

\[
\neg\mathsf{Core}^{\rm cmp},
\qquad
\neg\mathsf{Aspect}^{\Phi}_{G},
\qquad
\text{or failure of CFD}.
\]

It shows only that a rich publicly available first-person transcript may still lack the complete finite information demanded by the current G3 classifier.

## 5. Consequence

The P0 result puts pressure on practical scope, not on truth:

\[
\text{public descriptive richness}
\not\Rightarrow
\text{G3 complete-mode eligibility}.
\]

A continuing exploratory web pilot may log more archival items under the same trichotomy:

\[
\text{complete-codeable},
\qquad
\text{incomplete/out-of-scope},
\qquad
\text{semantically inconsistent}.
\]

It may not report selector accuracy, match rates, rival defeat, or framework support.

## Nonclaims

This single archival feasibility result does not estimate any rate, generalize to DES, question the fidelity of the report, or alter the frozen confirmatory protocol.
