# Primary-source verification matrix — problem of time

**Audit date:** 19 October 2026  
**Purpose:** targeted verification for WP0 (gravitational clock comparison) and WP1 (relational dynamics with non-ideal clocks).  
**Status:** source screening and selected-section audit; not a complete independent proof audit. No source below is being represented as a general solution of the problem of time.

## Audit labels

- **M** — bibliographic identity and version checked against the primary record.
- **A** — abstract/introduction or conclusion checked in the primary source.
- **S** — targeted technical sections/equations checked in the primary source.
- **F** — full derivation/proof audit complete. **No source has F status.**
- **Hold** — do not use the claim beyond the stated scope until the listed verification is complete.

Primary-source links are in the first column. Current arXiv versions are specified explicitly; an older preprint should not be substituted silently where the version matters.

## Verified findings that change the work order

1. **A same-state, same-subregion gravitational clock comparison exists already in the perturbative QRF literature.** De Vuyst et al. §8.1 is the feasibility-first WP0-A benchmark. Its comparison is between observer-defined subalgebras, so the report must state whether the shared algebra is nontrivial and must not present differing entropies as predictions for an identical observable set when they are not.
2. **The specific York-time JT source is a one-clock construction.** Blommaert–Chen provide a strong candidate for a nonperturbative-in-\(G_N\), fixed-topology model, but no same-model, two-clock comparison has been verified. The paper’s references to an observer clock and an inflaton clock point to separate prior constructions. WP0-B must add a second clock to one common JT+CFT theory or state why this cannot be done.
3. **York time is not a universal selection principle.** In one JT paper it is the chosen geometric clock for constructing observables; in another it parameterizes a unitary change of length basis at fixed boundary time. Neither alone proves that all physically meaningful clocks are equivalent or that York time is uniquely selected.
4. **Entropy comparison requires its own normalization/objective audit.** Compare entropy functionals’ state-dependence, entropy differences, or relative entropies unless a canonical trace normalization is fixed. Report the full patch algebra separately from a clock-restricted regional algebra.
5. **The WP1 finite-clock result is protocol-sensitive.** TO and PM approaches agree in the ideal limit but differ at finite resources because they describe distinct operational measurement implementations. Count external ordering/control resources explicitly; do not infer fundamental discreteness from the conditional discrete-time construction.
6. **No source screened here reaches the requested Level C endpoint.** These sources support model-specific theorems and constructions. The general theory class, clock-selection/covariance rule, full constraint consistency, proper-time recovery, and closure audit remain open. Level D remains a separate empirical-discrimination track.

## Interpretive classification note: relational time is not the same test as background independence

This note is a scope clarification for the master plan, not a new WP0/WP1 result. The sources below were checked at abstract/introduction or selected-section level only; this is not a full survey of string/M-theory formulations.

- **Conventional perturbative string theory:** the conventional perturbative setup begins from a classical target-space background and treats string propagation and perturbations relative to it. This supports rejection under a strict “no prescribed target-space structure at the fundamental level” filter. It does not establish that every perturbative background has a global, stationary, external time; state the fixed spacetime structure rather than making “background time” a universal property. [7](https://arxiv.org/html/1201.6606)
- **String field theory:** do not grant an automatic pass. A 2026 analysis finds that the verdict depends on the chosen definition and formulation; specific background-equivalence results cover restricted classes, such as marginal deformations of world-sheet theories, rather than establishing a universal completion. [1](https://link.springer.com/article/10.1007/s10701-026-00925-x) [10](https://link.springer.com/article/10.1007/JHEP02(2018)155)
- **M-theory:** “a background-independent M-theory would pass” is a conditional criterion, not an assessment of an available complete formulation. This source audit does not establish the current status of every proposed M-theory framework; any concrete candidate must be named and evaluated against the same fixed-structure test. [1](https://journals.aps.org/rmp/abstract/10.1103/RevModPhys.73.419)
- **JT/York-time construction:** Blommaert–Chen use a fixed-topology JT model, nonperturbative in \(G_N\) within that sector, with fixed boundary-dilaton data; York/conformal time is used to dress relational bulk observables. Classify it as relational-clock work in a model with fixed topological/boundary structure—not as a perturbative gravitational QRF construction or a background-free fundamental theory. De Vuyst et al. is the distinct perturbative gravitational QRF example. The separate Parrikar–Sake York-time wavefunction construction explicitly holds boundary time fixed, so the two JT papers must remain separate. [2](https://arxiv.org/html/2602.22153) [1](https://arxiv.org/abs/2412.15502) [2](https://arxiv.org/html/2505.19231)
- **Comparison label:** DEHK §8.1 is a same-state, same-region comparison of clock-relative constructions, but the algebras differ. Call it a same-state observer-dependent-algebra/entropy-functional comparison. Call it a same-observable clock comparison only if a nontrivial common algebra or a matched relational task is demonstrated. Different algebras are not an invalid comparison; they answer a different question.

These categories are orthogonal: a model may use relational bulk time while retaining fixed boundary/topology data, and a formulation may seek background independence without furnishing a physical clock or relational observables. A metaphysical filter can state a preference or requirement; it cannot establish the construction’s adequacy or uniqueness.
