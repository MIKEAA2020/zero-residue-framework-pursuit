# Strong-CI No-Go Scope Audit v1
## Can a non-question-begging impossibility theorem be stated?

## Result

A global theorem of the form

\[
\forall F\;\neg\mathsf{SCI}(F)
\]

is not presently stateable with a non-question-begging scope and explanatory predicate. The repeated failure of reviewed candidates is therefore not evidence sufficient for global impossibility.

A narrower, valid conditional result is available: parameter-free public determination cannot uniquely select a member of a non-singleton automorphism-transitive modal orbit. This is a limitation on a specified thin/symmetric articulation class, not a refutation of all whole-reality frameworks.

## 1. Requirements for a global no-go theorem

A global result would need a class \(\mathcal C_{\rm all}\) satisfying:

\[
\forall F\,[\mathsf{WholeRealityFramework}(F)\rightarrow F\in\mathcal C_{\rm all}],
\]

together with a shared, noncircular predicate \(\mathsf{SCI}\) that decides when a fact is intelligibly explained rather than primitive, circularly asserted, or regressively deferred.

Neither requirement is currently met.

### 1.1 Scope problem

An extensional class assembled from known candidates—classical theism, participation, whole-first views, mathematical realism, nondual appearance, structural views, and so on—does not include unknown candidate families. It cannot support a conclusion about every possible framework.

An intensional definition has the opposite difficulty. If it builds in that every ultimate explanation must have a well-founded explanatory source distinct from what it explains, it excludes identity, holistic, non-well-founded, or primitive-necessity accounts by definition. Calling all of those failures before argument makes the theorem stipulative.

### 1.2 Predicate problem

The proposed exhaustive failure trilemma is usually:

\[
\text{brute termination}\ \vee\ \text{regress}\ \vee\ \text{circularity}.
\]

It is not exhaustive until one gives a theory of explanation that decides the status of, for example:

\[
\text{identity explanation},
\quad
\text{reciprocal/holistic explanation},
\quad
\text{necessary structural explanation},
\quad
\text{primitive explanatory laws}.
\]

Classifying each as brute or viciously circular without an independent criterion would build the no-go conclusion into \(\mathsf{SCI}\).

## 2. A narrow admissible no-go lemma

Let \(\mathcal M\) be a semantic structure with a set \(O\) of candidate modal tokens and an automorphism group \(\operatorname{Aut}(\mathcal M)\). Let \(O\) be a non-singleton orbit on which \(\operatorname{Aut}(\mathcal M)\) acts transitively.

Call a token \(m\in O\) **publicly parameter-free determined** iff there is a formula \(\varphi(x)\), using only the declared public vocabulary and no parameters naming modal tokens, such that:

\[
\mathcal M\vDash \varphi(m)
\quad\text{and}\quad
\mathcal M\vDash\forall x\,[\varphi(x)\rightarrow x=m].
\]

### Lemma

\[
|O|>1\ \land\ \operatorname{Aut}(\mathcal M)\text{ transitive on }O
\quad\Rightarrow\quad
\text{no }m\in O\text{ is publicly parameter-free determined.}
\]

### Proof

Assume \(m\in O\) is uniquely defined by \(\varphi(x)\). Because \(O\) has more than one member and the action is transitive, there is an automorphism \(\sigma\) with \(\sigma(m)\ne m\). Parameter-free formulae are invariant under automorphisms, so:

\[
\mathcal M\vDash\varphi(m)
\quad\Rightarrow\quad
\mathcal M\vDash\varphi(\sigma(m)).
\]

This contradicts uniqueness of \(m\). Therefore no such \(\varphi\) exists. \(\square\)

## 3. What the lemma does and does not show

It shows that an articulation proposal with all of the following features cannot publicly derive a distinguished finite modal item:

\[
\begin{array}{l}
\text{a parameter-free public vocabulary;}\\
\text{a non-singleton symmetric orbit of candidate modes;}\\
\text{a demand for individual unique determination within that orbit.}
\end{array}
\]

This restates and sharpens the thin-\(K_{\rm SK}\) / finite-articulation pressure in a representation-independent form.

It does **not** show that:

\[
\forall F\;\neg\mathsf{SCI}(F),
\]

or that no framework can contain modes. A framework could deny the demand for an individually distinguished member, use an independently justified asymmetry, treat a whole profile rather than individual tokens as primary, or formulate a non-model-theoretic articulation relation. Each move creates a new burden; none is refuted by this lemma alone.

## 4. Escape audit

| Proposed escape | Result of this audit |
|---|---|
| Add a parameter naming the mode | Avoids the lemma but supplies rather than derives the differentiation; a selector/individuation audit is required. |
| Add asymmetric primitive structure | Avoids the lemma only if the primitive has independent semantics and is not the desired modal profile restated. |
| Treat an entire symmetric profile as determined | Avoids individual selection, but still requires an account of why that profile and how finite particulars are articulated. |
| Appeal to a necessary ground-nature | Does not by itself select members of a symmetric orbit; it needs an exact-profile bridge. |
| Reject model-theoretic semantics | Escapes the lemma's scope, but then must provide another public determination criterion. |

## 5. No-go programme decision

The global negative track is **not yet admissible**. Its first research output is only:

\[
\boxed{
\text{A global non-question-begging scope class and shared SCI predicate have not been supplied.}
}
\]

The permissible negative work product is a finite family of explicitly scoped conditional no-go lemmas, each with its escape audit. These lemmas may expose burdens and eliminate a formal subfamily; they may not be aggregated into a verdict that strongest CI is unsatisfiable unless an independently defended exhaustiveness theorem is later proved.

## Nonclaim

This audit does not establish that the articulation problem is insoluble, that the current candidate frameworks are false, or that a correct framework cannot be discovered. It distinguishes one valid symmetry/definability limitation from an unearned global impossibility claim.
