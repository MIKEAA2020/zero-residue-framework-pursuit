## 2. Defended source grammar: Minimal Directed Differentiation

The source grammar is governed by the following explicit principle:

\[
\boxed{
\mathsf{CausalPotency}(P)
\land
\mathsf{ActualDirectedArticulation}(P)
\Longrightarrow
\mathsf{MinimalDirectedDifferentiation}(P).
}
\tag{MDD}
\]

\(\mathsf{MinimalDirectedDifferentiation}\) has a restricted meaning. It says that a nontrivial directed articulation has the least possible finite outgoing discrimination, namely the least natural number greater than one:

\[
\mathsf{arity}_{\rm MDD}
=
\min\{n\in\mathbb N:n>1\}
=2.
\tag{MINIMAL-ARITY}
\]

The two successor operations are not independent substances, spatial directions, temporal ticks, or physical alternatives. They are the two formal operations required by the minimal nonunit directed grammar:

\[
\mathsf{s}_0,
\mathsf{s}_1:C_\star\to C_\star.
\tag{SUCCESSOR-OPERATIONS}
\]

The order carrier is the least closure containing a root \(\epsilon\) and closed under these operations:

\[
C_\star
=
\bigcap\{X:
\epsilon\in X
\land
\mathsf{s}_0[X]\subseteq X
\land
\mathsf{s}_1[X]\subseteq X
\}.
\tag{LEAST-CLOSURE}
\]

The operations are required to have disjoint images and no fixed points:

\[
\mathsf{s}_0(x)\neq\mathsf{s}_1(y),
\qquad
\mathsf{s}_i(x)\neq x
\qquad(i\in\{0,1\}).
\tag{NONDEGENERATE-GRAMMAR}
\]

The strict precedence relation is generated, not simply named causal:

\[
\begin{aligned}
x\prec_\star y
\iff{}&
\exists n\geq1\ \exists i_1,\ldots,i_n\in\{0,1\}\,[\\
&y=\mathsf{s}_{i_n}\circ\cdots\circ\mathsf{s}_{i_1}(x)].
\end{aligned}
\tag{GENERATED-ORDER}
\]

The source grammar is therefore a new positive commitment. The arity-two result follows from the stipulated minimality rule, not from an unexplained alphabet \(\{0,1\}\). Whether MDD itself is independently defensible is a later gate, not an established result.

## 4. Causal semantics: intervention asymmetry rather than relabeling

To test whether generated order can bear causal rather than merely ordinal content, CO-2 supplies a finite structural-equation interface. Each locus \(x\in C_\star\) has a prephysical register \(X_x\in\{0,1\}\). The root and successor equations are:

\[
X_\epsilon=1,
\qquad
X_{\mathsf{s}_0(x)}=X_x,
\qquad
X_{\mathsf{s}_1(x)}=1-X_x.
\tag{STRUCTURAL-EQUATIONS}
\]

These equations contain no metric, spatial coordinate, elapsed duration, particle, field, observer, or empirical physical law. The candidate's causal relation is **not** defined as \(\prec_\star\). It is defined by intervention-sensitive directed dependence:

\[
\begin{aligned}
\mathsf{GenCauses}(x,y)
\iff{}&
\exists b\neq b'\in\{0,1\}
[\mathsf{Value}_{\mathrm{do}(X_x:=b)}(X_y)\\
&\hspace{26mm}\neq
\mathsf{Value}_{\mathrm{do}(X_x:=b')}(X_y)]\\
&\land
\neg\exists c\neq c'\in\{0,1\}
[\mathsf{Value}_{\mathrm{do}(X_y:=c)}(X_x)\\
&\hspace{26mm}\neq
\mathsf{Value}_{\mathrm{do}(X_y:=c')}(X_x)].
\end{aligned}
\tag{INTERVENTION-CAUSALITY}
\]

The frozen target theorem is:

\[
\mathsf{GenCauses}(x,y)
\iff
x\prec_\star y.
\tag{CAUSAL-ORDER-TARGET}
\]

This theorem must be checked rather than assumed. If it fails, formal order has not acquired even the proposed prephysical causal semantics.

The relation remains prephysical even if the theorem holds:

\[
\mathsf{GenCauses}(x,y)
\not\Rightarrow
\mathsf{PhysicalCausation}(x,y).
\tag{PREPHYSICAL-CAUSAL-LIMIT}

\[

The witness is admissible only if all target and empirical items are independently specified before recovery evaluation.

The faithful-recovery condition is:

\[
\begin{aligned}

\mathsf{DimensionEstimate}(C_{\rm fin})=d\\

\mathsf{OrderDistortion}(C_{\rm fin},\Phi)\leq\epsilon_{\rm ord}.
\end{aligned}
\tag{FAITHFUL-RECOVERY}

The physical-observable interface is separate:

\[

\tag{OBSERVABLE-RECOVERY}

No actual \(\mathcal R\) is supplied by this preregistration. The map is a condition for a later physical claim, not a current manifold or physics result.
