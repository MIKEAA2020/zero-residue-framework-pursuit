# Explicit Modal-Creatorship Independent Rival Family — Preregistration v1
## An independent family under the common comparison protocol; not a PPA bridge or variant

**Family designation:** \(\mathcal F_{\rm EMC}\) — *Explicit Modal-Creatorship*  
**Standing:** independently specified family preregistration; not an EntryPacket; no battery is authorized.  
**Relation to other lines:** \(\mathcal F_{\rm EMC}\) is neither a PPA successor nor a point–sphere/strict-pure-negation Appearance bridge.

\[
\boxed{
\mathcal F_{\rm EMC}\not\simeq\mathcal F_{\rm PPA}
\qquad\land\qquad
\mathcal F_{\rm EMC}\not\simeq\mathcal F_{\rm Appearance}.
}
\tag{INDEPENDENCE}
\]

It is not permitted to redescribe modal possibility, personal agency, actual selection, creation, or real creature/creator distinction as neutral formal structure. Those are its openly declared primitives or commitments.

## 1. Scope and nonclaims

\(\mathcal F_{\rm EMC}\) models a necessary personal ground, an explicitly declared possibility domain, atemporal creative actualization, and a real distinction between the ground and creatures. It does **not** claim classical strict simplicity, a pure-negation metaphysics, a nonbrute selector account, empirical physics recovery, or a zero-residue victory.

\[
\boxed{
\mathsf{Scope}(\mathcal F_{\rm EMC})
=
\mathsf{IndependentModalCreatorshipFamily}
\land
\mathsf{DeclaredModalAndVolitionalPrimitives}.
}
\tag{SCOPE}
\]

In particular:

\[
\neg\mathsf{Claimed}\bigl(\mathsf{NonBrute}(	ext{actual-world selection})\bigr),
\qquad
\neg\mathsf{Claimed}\bigl(\mathsf{ZRPass}(\mathcal F_{\rm EMC})\bigr).
\tag{NO-ZR}
\]

## 3. Explicit modal and actuality architecture

### 3.1 Possibility domain

The possibility domain is a primitive, publicly declared component of this family:

\[
\mathcal W_{\rm poss}
=
\{[w]\in\overline{\mathbf W}:\mathsf{Poss}([w])\}.
\tag{POSS-DOMAIN}
\]

It is not inferred from consistency, naming, code availability, or the PPA applicability relation.

### 3.2 Atemporal creative actualization

\(\mathsf{Chooses}(D,[w])\) is a primitive atemporal personal-actualization relation. It is explicitly **not** an event at a time prior to the created world:

\[
\mathsf{Chooses}(D,[w])
\not\Rightarrow
\exists t\in\mathbf T\,\mathsf{ChoosesAt}(D,[w],t).
\tag{ATEMPORAL-CHOICE}
\]

The world-actuality rule is:

\[
\boxed{
\mathsf{ActualWorld}([w])
\iff
\mathsf{Poss}([w])
\land
\mathsf{Chooses}(D,[w])
\land
\mathsf{Creates}(D,[w]).
}
\tag{WORLD-ACTUALITY}
\]

The family additionally requires one actual world-class at its full-candidate stage:

\[
\exists![w]\in\overline{\mathbf W}\,\mathsf{ActualWorld}([w]).
\tag{UNIQUE-ACTUAL-WORLD}
\]

Created actuality is then typed by membership in that selected world-class:

\[
\boxed{
\mathsf{ActualCreated}(c)
\iff
\exists[w]\,[
\mathsf{ActualWorld}([w])
\land
\mathsf{ExistsIn}(c,[w])].
}
\tag{CREATED-ACTUALITY}
\]

### 3.3 Real distinction and dependence

\[
\mathsf{ActualCreated}(c)
\Longrightarrow
c\neq D
\land
\mathsf{DependentOn}(c,D).
\tag{REAL-DISTINCTION}
\]

The creator/creature distinction is not treated as an appearance-only contrast, an identity claim, or an untyped code relation.
