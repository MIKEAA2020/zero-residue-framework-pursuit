# Point–Sphere Bare-Core Spacetime Baseline BSC-1
## Parallel preregistration for strong and weak simplicity without added source postulates

**Status:** Preregistered only. This is a deliberately austere baseline comparison, not a proposed complete framework and not a refutation of strong or weak simplicity.

**User-selected rule:** Give neither route extra source postulates. Test exactly what strong privation and weak simplicity alone can generate before causal potency, immanent determination, privative grammar, relations, possible worlds, observers, space, time, mathematics of physical structure, or recovery maps are added.

**Fresh baseline pair:**

- **BSC-1S:** bare strong simplicity.
- **BSC-1W:** bare weak simplicity, with permission for positive immanent differentiation but without positing any actual differentiation.

---

## 1. Nonliteral Point–Sphere control

Point and Sphere remain nonliteral:

\[
\mathsf{Point}\neq\text{geometrical point},
\qquad
\mathsf{Sphere}\neq\text{geometrical sphere}.
\]

At the bare baseline, no independently structured Sphere is assumed. “Sphere” means only the possible downstream role of a Point–Sphere candidate; no such role is generated or posited here.

\[
\mathsf{BarePoint}
\not\Rightarrow
\mathsf{ActualSphereStructure}.
\]

---

## 2. Bare strong and weak cores

The bare strong core is:

\[
\mathsf{StrongBare}(P)
:iff
\mathsf{NoProperParts}(P)
\land
\mathsf{NoComposition}(P)
\land
\mathsf{NoRealInternalFormalDifferentiation}(P)
\land
\mathsf{NoSpatialLocation}(P)
\land
\mathsf{NoTemporalIndex}(P).
\]

The bare weak core is:

\[
\mathsf{WeakBare}(P)
:iff
\mathsf{NoProperParts}(P)
\land
\mathsf{NoIndependentConstituents}(P)
\land
\mathsf{NoSpatialLocation}(P)
\land
\mathsf{NoTemporalIndex}(P).
\]

The difference is important:

\[
\mathsf{WeakBare}(P)
\not\Rightarrow
\neg\mathsf{PositiveImmanentDifferentiation}(P),
\]

but permission is not actuality:

\[
\mathsf{WeakBare}(P)
\not\Rightarrow
\mathsf{ActualPositiveImmanentDifferentiation}(P).
\]

---

## 3. No-supplement rule

The only formal token allowed in either baseline is a single bearer marker \(\bullet\). The bare language contains equality only:

\[
\mathcal L_{\rm bare}
=
\langle\bullet,=\rangle.
\]

Its carrier is:

\[
B:=\{\bullet\}.
\]

The following are explicitly unavailable as premises, constructors, or hidden output codes:

\[
\begin{aligned}
&\text{positive differentiation tokens,}\quad
\text{privation tokens,}\quad
\text{binary relations,}\quad
\text{orders,}\\
&\text{sets of alternatives,}\quad
\text{modal ranges,}\quad
\text{selectors,}\quad
\text{causal powers,}\\
&\text{spatial or temporal coordinates,}\quad
\text{metrics,}\quad
\text{fields,}\quad
\text{observers,}\\
&\text{state spaces,}\quad
\text{dynamics,}\quad
\text{recovery maps,}\quad
\text{empirical data.}
\end{aligned}
\]

No structure is imported merely by using set-theoretic notation for the one-token test carrier.

---

## 4. Noncircular derivability criterion

A structure counts as baseline-derived only if it is definable from the one-token equality language without adding a nonidentity relation, operator, parameter, range, or selection rule:

\[
\mathsf{BareDerived}(Q)
\Longrightarrow
\mathsf{Definable}_{\mathcal L_{\rm bare}}(Q).
\]

A relation intended to be a nontrivial strict causal order must satisfy:

\[
\mathsf{NontrivialStrictOrder}(R)
\Longrightarrow
\mathsf{Irreflexive}(R)
\land
\mathsf{Transitive}(R)
\land
\mathsf{Nonempty}(R).
\]

A spacetime-first seed requires at least a nontrivial prephysical structure and directed order:

\[
\mathsf{SpacetimeSeed}
\Longrightarrow
\mathsf{NontrivialStructure}
\land
\mathsf{DirectedOrder}.
\]

---

## 5. Authorized audit

The sole audit is:

\[
\begin{array}{c|l}
\mathsf{B0} & \text{does each baseline obey the no-supplement rule?}\\
\mathsf{B1} & \text{does the equality-only one-token baseline derive a nontrivial strict order?}\\
\mathsf{B2} & \text{does either baseline derive the minimum seed required for a spacetime witness?}
\end{array}
\]

No physics, causal reality, ontological grounding, or framework-selection test is authorized.

---

## 6. Expiry and result discipline

BSC-1S and BSC-1W expire after the one B0–B2 audit.

\[
\mathsf{Expiry}(C)
:=
\mathsf{Complete}(\mathsf{B0}(C)\land\mathsf{B1}(C)\land\mathsf{B2}(C)).
\]

A baseline failure to generate a structure does not refute a core that is supplemented by genuine additional principles:

\[
\mathsf{BaselineNoGeneration}(C)
\not\Rightarrow
\mathsf{Refuted}(C)
\lor
\mathsf{Refuted}(\mathsf{StrongSimplicity})
\lor
\mathsf{Refuted}(\mathsf{WeakSimplicity}).
\]

A later supplemented proposal must be a fresh candidate and must state exactly what is newly added.

---

## 7. Pre-audit conclusion

The baseline comparison tests a narrow but indispensable question:

\[
\text{Does bare simplicity itself generate a first nontrivial physics-relevant structure?}
\]

It does not prejudge whether a later strong privative grammar or weak immanent-differentiation bridge can do so.
