# Nondual Articulation Dossier A1 — Structural-Functional Criterion Test v1
## Testing the strongest role-occupancy proposal for \(\mathsf{Genuine}(m)\)

## Status

This document tests a proposed structural-functional criterion. It is not a definition established as true, a proof of nondual articulation, or a framework verdict.

## 1. Critical correction

The contrast between “substantive” and “structural-functional” definitions is not itself a solution to the articulation problem. A role description becomes a genuine membership criterion only if its roles can be specified without presupposing the mode inventory, the dependence relation, the individuation relation, or the property/substance distinction that it is meant to explain.

In particular, the assumptions that properties are repeatable and modes are unique cannot be used as a general boundary. Unrepeatable tropes, unique properties, and repeatable/qualitatively recurring modal presentations show that repeatability is not a framework-neutral type test.

## 2. Strongest available structural-functional proposal

Let

\[
\mathcal K_G=\langle P,R,\Pi_G\rangle
\]

be a purported structure internal to the ground, where \(P\) is a set of positions, \(R\) a family of structural relations, and \(\Pi_G\) a declared profile extractor. Define an individually determined position by:

\[
\mathsf{Indiv}_{\Pi_G}(p)
\iff
\forall q\in P\,[
\mathsf{Prof}_{\Pi_G}(q)=\mathsf{Prof}_{\Pi_G}(p)
\rightarrow q=p
].
\]

The strongest charitable role-occupancy proposal is:

\[
\begin{aligned}
\mathsf{SF}_0(m,G)\iff\exists p\in P\,[
&\mathsf{Realizes}(m,p,G)\land
\mathsf{Internal}(p,\mathcal K_G)\\
&\land\mathsf{Indiv}_{\Pi_G}(p)
\land\mathsf{Dep}_{G}(m)\\
&\land\mathsf{NonSub}(m)
\land\mathsf{NonProp}(m)
].
\end{aligned}
\]

This formulation gives the proposal every initial advantage: it treats determination structurally, demands dependence, and overtly blocks substance/property collapse.

## 3. What \(\mathsf{SF}_0\) must independently supply

For \(\mathsf{SF}_0\) to be a public criterion rather than a relabelling, it needs truth conditions for each nonlogical predicate:

\[
\mathsf{Realizes},\quad
\mathsf{Internal},\quad
\mathsf{Dep}_{G},\quad
\mathsf{NonSub},\quad
\mathsf{NonProp},\quad
\Pi_G.
\]

None may be defined as “the relation/feature that genuine modes have.” In particular:

\[
\mathsf{Dep}_G(m)\iff
\text{“}m\text{ is constituted by }G\text{’s self-knowledge”}
\]

is not a public truth condition while “a self-knowledge content” is the disputed mode relation. It relabels \(A2\).

Likewise, \(\mathsf{Realizes}(m,p,G)\) either presupposes a relation from a candidate mode to a position, or treats positions as the modes. In the first case it needs independent semantics; in the second it does not distinguish role from occupant.

## 4. Structural-case adjudication

| Case | \(\mathsf{SF}_0\) result | Audit result |
|---|---|---|
| T0: no candidate positions | No \(m\) satisfies \(\mathsf{SF}_0\). | Formally determinate but says nothing about whether the ground may have no finite modes. |
| T1: one candidate position | \(\mathsf{Indiv}\) is available. | Conditional only: realization, dependence, non-substantiality, and non-propertyhood remain undefined. |
| T2: non-singleton transitive orbit | No individual position is \(\mathsf{Indiv}\). | The automorphism lemma blocks individual public determination. Treating the whole orbit as a content changes the target from particular modehood to profile-level articulation. |
| T3: property candidate | Requires \(\mathsf{NonProp}\). | No framework-neutral criterion is supplied. Repeatability cannot do the work. |
| T4: independent candidate | Requires \(\mathsf{NonSub}\) and \(\mathsf{Dep}_G\). | No noncircular independence/dependence criterion is supplied; this is the downstream \(D\) problem. |
| T5: profile-conservative re-encoding | Verdict is invariant only if \(\Pi_G\), \(P\), and \(R\) are already independently preserved. | The criterion assumes, rather than supplies, its invariance base. |
| T6: token added without public semantic resource | If the new token is structurally symmetric, \(\mathsf{Indiv}\) fails; if it changes \(\mathcal K_G\), its new structure is an added resource. | \(\mathsf{SF}_0\) does not derive the token. |

## 5. Failure analysis

The proposal fails the A0 admissibility criterion as a sufficient \(\mathsf{Genuine}(m)\) condition.

\[
\boxed{
\mathsf{SF}_0\text{ is a role description conditional on an already typed modal ontology, not a public mode-membership criterion.}
}
\]

Its failure is localized. The result is not that structural relations are irrelevant; it is that each required relation inherits a prior burden:

\[
\begin{array}{rcl}
\mathsf{Realizes} &\rightsquigarrow& \text{mode/position semantics};\\
\mathsf{Dep}_G &\rightsquigarrow& \text{non-temporal dependence semantics};\\
\mathsf{NonSub} &\rightsquigarrow& \text{independence/substance criterion};\\
\mathsf{NonProp} &\rightsquigarrow& \text{property/mode criterion};\\
\mathsf{Indiv}_{\Pi_G} &\rightsquigarrow& \text{identity, asymmetry, and profile semantics};\\
\Pi_G &\rightsquigarrow& \text{representation-invariance bridge}.
\end{array}
\]

Thus role-occupancy does not decompose the articulation burden into solved parts. It displays its dependency graph.

## 6. Why invariance is necessary but insufficient

A criterion that changes under a profile-conservative reformulation is inadmissible. But invariance alone cannot establish that a stable role is a genuine mode:

\[
\text{invariance}
\not\Rightarrow
\text{modehood},
\qquad
\text{invariance}
\not\Rightarrow
\text{dependence},
\qquad
\text{invariance}
\not\Rightarrow
\text{particularity}.
\]

Moreover, if \(\Pi_G\) is selected only after choosing the desired positions and relations, an invariance claim merely preserves the assumed inventory. The profile extractor must be independently declared and shared with rivals before it can bear evidential weight.

## 7. Dossier outcome and next permitted move

Under the A0 expiry rule, \(\mathsf{SF}_0\) expires as a proposed sufficient articulation criterion:

\[
\mathsf{SF}_0\not\models
\mathsf{Genuine}(m)
\text{ with public, noncircular truth conditions.}
\]

This does not refute nonduality or prohibit a future articulation account. It rules out only the inference that a generic structural-functional role, without independent semantics for its constituent relations, solves A3.

The next permitted constructive move is not to add another informal label. It must either:

1. independently type one of the prerequisite relations—especially non-temporal dependence or mode/property distinction—using predeclared cases and a shared profile extractor; or
2. record the nondual dossier’s A3 stage as unresolved and begin an equal-burden dossier for a rival candidate.

## Nonclaim

No claim is made that a simple ground cannot have modes, that all role-functional accounts fail, or that the nondual candidate is false. The result is a failed attempt to use \(\mathsf{SF}_0\) as the missing public-determination criterion.
