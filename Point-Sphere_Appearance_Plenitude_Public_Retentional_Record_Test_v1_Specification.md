# AP4A Public Retentional Record Test v1
## Family-level discriminator for public ordered records

## Purpose

AP3 established a conditional finite-mode grammar only up to five structural families. AP4 now asks a different question: which families can support a **public retentional record** between finite contexts?

This is not an AP3 axiom smuggled backward to choose a mode grammar. It is a downstream public-record requirement. It may condition which grammar families can implement publicly shared finite appearance.

## Public record definitions

For distinct mode contexts \(C,D\), let
\[
R_{CD}=C\cap D.
\]

- An **elementary public datum** exists when \(|R_{CD}|\ge1\).
- A **public retentional record** exists when \(|R_{CD}|\ge2\) and the two shared contents inherit one coherent nontrivial local order from AP3N:
\[
\exists r_1,r_2\in R_{CD}\quad r_1\prec_C r_2
\ \land\ r_1\prec_D r_2.
\]

The minimum two-content condition has an independent AP4 rationale: one shared content can be a common datum, but it cannot instantiate a shared ordered record of continuity/change. A public retentional record requires at least an ordered pair of jointly accessible contents.

## Family-level requirements

Test the five AP3 grammar families under:

1. **D1 elementary publicity:** some distinct context pair shares a datum.
2. **D2 universal public-record participation:** every context has some other context with which it shares a public retentional record.
3. **D3 order coherence:** the shared ordered pair agrees in both local orders.
4. **D4 no background time:** the order is inherited from AP3N’s endogenous retentional relation, not an external clock.

## Registered target

- All five families should pass D1.
- Only the IAR-like overlapping-triple/diamond family should pass D2–D4 in the minimal four-content model.

## Interpretation rule

If the target obtains, the result is conditional:

> Among the minimal AP3 grammar families, the IAR-like family is uniquely capable of giving every context a two-content, order-coherent public record interface.

It does not prove IAR as the unique grammar of all finite appearance. It says only that a public-record implementation with this minimum requirement selects it in this finite family. Physical record dynamics, redundancy, Born probabilities, and spacetime remain unaddressed.
