# Point–Sphere Appearance/Plenitude: Topological Research Programme v1
## Conditional formal branch; ordered by dependency, then feasibility

## Status and scope

This programme develops the newly steelmanned architecture as a **conditional research branch**:

> one simple non-derivative ground; finite reality as real modes/aspects rather than a numerically independent created substance; and necessary plenitude understood as realisation of globally admissible, non-gauge aspect structure.

It does **not** silently replace the canonical protected hard core, prove the architecture, or reclassify it as physics. It is a route for testing whether the proposal can become a coherent formal/physical programme. Existing T1–T6 Problem-of-Time results and the F2 cancellation remain controlling.

## Feasibility-priority rule

At any time, execute only a node whose predecessors are complete. Among such nodes, choose the highest-feasibility node that can expose a decisive ambiguity. This prevents both premature physics claims and endless preparatory audit.

Under this rule, **AP0 and AP1 are first**. AP1 is not a proof of plenitude. It is the essential test of the restricted inference:

\[
\text{bare no preference}\;\not\Rightarrow\;\text{realise all aspects}
\]
without stated assumptions. AP2 tests the proposed non-structural assumption set: complete self-knowing awareness plus a valid identity between genuine self-aspect and non-representational self-presentation. If that package holds, plenitude is conditionally derived by identity; orbit symmetry is then a consistency constraint, not the source of the derivation.

## AP0 — frozen typing

| Term | Role in this programme | Explicit nonclaim |
|---|---|---|
| Ground \(G\) | Metaphysical/non-structural commitment; never inserted as a node or vector in a physical toy model | A mathematical point, state, or group fixed point is not \(G\) |
| Description space \(\Omega\) | Formal representations available to a model | Distinct descriptions are not automatically distinct aspects/worlds |
| Gauge group \(K\) | Redundancy acting on \(\Omega\) | Gauge copies are not multiplied by plenitude |
| Physical aspect space \(\mathcal A=\Omega/K\) | Candidate distinct modal/aspect structures in a declared model | A finite toy \(\mathcal A\) is not the landscape of all reality |
| Physical symmetry group \(H\) | A substantive action on \(\mathcal A\) | Ground simplicity does not itself provide an \(H\)-action |
| Admissibility \(\mathsf A\) | Rule defining which aspects are in the model domain | Local consistency is not automatically global admissibility |
| Realisation \(R\) | Predicate/measure identifying realised aspects | Symmetry alone does not define \(R\) |
| Mode/perspective | Future bounded-access structure within a realised physical aspect | A mode is not yet a subject merely by being named |

## AP1 — frozen finite theorem target

Let a finite physical aspect set \(\mathcal A\) carry a transitive action of a finite group \(H\). Let a realisation support be \(R\subseteq\mathcal A\).

1. If \(R\) is \(H\)-invariant, then transitivity implies \(R\) is either empty or all of \(\mathcal A\).
2. Hence **nonempty**, invariant realisation entails full-orbit realisation.
3. Symmetry does not supply nonemptiness, identify \(\mathcal A\), prove that \(H\) is physical rather than gauge, or supply probabilities on an infinite/nontransitive landscape.
4. A unique invariant selector is impossible on a nontrivial transitive orbit.

The executed finite diagnostic must verify all four statements while showing that gauge-fibre labels cannot count as aspects.
