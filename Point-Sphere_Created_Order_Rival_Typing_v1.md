# C1b Created-Order Rival Typing v1
## Active-belt comparison under the protected hard core

## Scope and fairness rule

The hard core already assumes real dependent creation. C1a fixed six architectural constraints: asymmetric dependence, internal time, differentiated/public structure, finite causal agency, located ignorance, and ethically non-null negative valence.

This document does **not** decide whether the hard core is publicly proven. It asks a narrower question: which rival *types*, as defined below, can satisfy those C1 constraints without revision? A type failure is not a refutation of every historical thinker or tradition associated with a label. In particular, “strict-ND/appearance” here means only a view on which finite differentiated creation is ultimately not real in the required sense; it is not a verdict about all non-dual traditions.

## Frozen rival profiles

| Profile | Operational definition for this diagnostic |
|---|---|
| **Conservation-only** | The ground originates the created order but does not sustain each created state/event in its being; finite causal laws thereafter suffice without present ontological dependence. |
| **Concurrence** | The ground sustains every created state/event in being while created causes retain irreducible causal roles internal to the created order. |
| **Occasionalism** | The ground is the only true efficient cause; creaturely causes are regular occasions or appearances. |
| **Strict-ND/appearance** | Differentiated finite creation, finite causal agency, or negative valence is ultimately only appearance, not real in the C1-required sense. |

The profiles are ideal types, not exhaustive philosophical taxonomies.

## Constraint typing

For each profile, record an architecture status:

- **Pass:** the profile contains the required feature by its own definition;
- **Fail:** it denies a required feature by its own definition;
- **Open:** it does not deny the feature but needs further positive construction.

| C1 constraint | Conservation-only | Concurrence | Occasionalism | Strict-ND/appearance |
|---|---:|---:|---:|---:|
| A. Every created state/event depends ontologically on the ground | Fail | Pass | Pass | Fail |
| B. Time is internal to created order | Open | Open | Open | Open |
| C. Differentiated public created structure is real | Pass | Pass | Pass | Fail |
| D. Finite agents have genuine created causal roles | Pass | Pass | Fail | Fail |
| E. Finite ignorance is a real located condition | Pass | Pass | Pass | Fail |
| F. Negative valence is ethically non-null | Pass | Pass | Pass, burden intensified | Fail |

## What follows—and what does not

1. **Conservation-only** is insufficient for C1-A as defined. A version that adds present sustaining dependence has moved toward a concurrence-type view and needs its own non-competition account.
2. **Occasionalism** retains radical dependence but fails the C1 requirement of genuine finite causal agency. Regular creaturely action may remain descriptively useful, but it is not the causal agency C1 requires.
3. **Strict-ND/appearance** conflicts with the protected commitment to real creation and therefore cannot serve as the programme’s internal created-order architecture. This says nothing about its possible external-rival role or about weaker non-dual views that retain real finite differentiation.
4. **Concurrence** is the only listed type that passes the C1 requirements by definition. This is a *survival result*, not a proof of concurrence. The central explanatory debt remains: give a positive non-competitive account of the relation between sustaining dependence and real finite causal powers.

## Positive concurrence target

A satisfactory C1c model must specify a relation \(\mathsf{Sustain}_E\) such that, for a created SCM \(\mathcal M_T\):

\[
\mathsf{Sustain}_E(\mathcal M_T)
\quad\text{and}\quad
X_j=F_j(\mathrm{Pa}_j,U_j)
\]

jointly hold without treating \(E\) as a rival member of \(\mathrm{Pa}_j\), and without making the \(F_j\) relations merely apparent. It must additionally state what explains this typing rather than assert it.

## Registered discriminator for C1c

A proposed concurrence bridge fails if it does any of the following:

1. inserts \(E\) as a created efficient-causal variable alongside finite causes;
2. removes finite intervention differences from the explanatory model;
3. invokes “different levels” without a rule linking the levels;
4. turns creaturely regularities into mere predictive appearance; or
5. erases negative valence by declaring finite differentiation unreal.

A candidate passes C1c only if it gives explicit types, bridge law(s), and at least one nontrivial toy model in which these failures are avoided.
