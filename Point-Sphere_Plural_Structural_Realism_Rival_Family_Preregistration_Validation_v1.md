## 2. Required quotient and type normalizations

### 2.1 Isomorphism transport of individual-orbit tokens

The source defines a role orbit within a representative \(S\), then writes an individual token using the structure class \([S]\):

\[
\iota_{[S],[u]_S}.
\tag{Orbit-Token}
\]

A full candidate must state how this token is invariant under a change of representative. For every isomorphism \(h:S\cong_{\rm str}T\), it must declare:

\[
\iota_{[S],[u]_S}
=
\iota_{[T],[h(u)]_T}.
\tag{Orbit-Transport}
\]

Without this transport clause, individual-orbit tokens remain representative-relative despite structure-level actuality being quotient-native.

### 2.2 Quotient-native local-pattern interface

The truth/error rule invokes \(\mathsf{LocalPattern}(S,[u]_S)\) while actuality is stated over \([S]\). A candidate must establish:

\[
S\cong_{\rm str}T
\Longrightarrow
\mathsf{LocalPattern}(S,[u]_S)
\cong_{\rm str}
\mathsf{LocalPattern}(T,[h(u)]_T).
\tag{Pattern-Transport}
\]

Only then does the intended matching rule support representation-invariant correctness rather than merely an invariant actual-structure predicate.

### 2.3 Meaning of “plural”

The source has a plural structural ontology but does not state whether plurality is asserted of actual structures, actual loci within one structure, or merely the candidate ontology. A full candidate must elect one stated condition, for example:

\[
\exists[S_0]\neq[S_1]\,
\bigl(
\mathsf{ActualStruct}([S_0])
\land
\mathsf{ActualStruct}([S_1])
\bigr),
\tag{Plural-Structures}
\]

or an explicitly different locus-level plurality rule. This prevents a nominally plural family from silently relying on one actual structure without a declared relation between the two readings.
