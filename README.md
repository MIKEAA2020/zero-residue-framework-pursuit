## Scope and claims discipline

`ARCHIVE_SCOPE.md` describes inclusion/exclusion rules. The materials record scoped arguments, formal constructions, checks, failures, and open problems. They do **not** collectively establish that a particular metaphysical framework is true, that a unique zero-residue framework exists, or that any numerical exercise establishes new fundamental physics.
