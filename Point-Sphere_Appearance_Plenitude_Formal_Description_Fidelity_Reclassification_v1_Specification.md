# AP3P3C Formal-Description / Ground-Fidelity Reclassification v1
## Evaluate the claim that grammar-derivation failure is a category mistake rather than an unfinished bridge

## Starting typing (already frozen by AP0)

\[
G:\text{ non-structural metaphysical ground},
\qquad
\Omega:\text{ formal description space},
\qquad
m:\text{ candidate finite mode/aspect},
\qquad
\mathcal M\in\Omega:\text{ a grammar/model}.
\]

AP0 already forbids treating \(G\) as a formal node, state, vector, or group fixed point, and already says distinct formal descriptions are not automatically distinct aspects/worlds.

## Valid reclassification

The following ground-to-grammar demand is ill-typed:
\[
G\Longrightarrow \mathcal M
\quad\text{as a formal construction theorem.}
\]

A non-structural ground need not literally contain a graph, valuation fibre, successor relation, or lift function. The 16 lifts are formal encodings in a specified model, not 16 structures in the ground.

The appropriate model-level question is instead:
\[
\mathsf{Fidelity}(\mathcal M,\mathsf{Target})?
\]
where the target may be finite self-presentation constraints, conditional phenomenological structure, record behavior, or a physical recovery regime.

## Necessary correction

The reclassification must not erase the grammar/content interface. From \(G\) being non-structural it does not follow that any grammar describes modes faithfully:
\[
G\text{ non-structural}
\not\Rightarrow
\mathsf{Fidelity}(\mathcal M,m).
\]

Nor does it turn a description-class theorem into an aspect-identity theorem:
\[
\mathcal M_f\cong\mathcal M_g
\Rightarrow
\text{one minimal description class},
\]
but not automatically one genuine mode/aspect absent a stated typing/fidelity bridge.

## Correct status of the 16 lifts

Under the minimal local-fibre signature:
\[
\{\mathcal M_f\}_{f\in(\mathbb Z_2)^4}
\]
forms one connected isomorphism groupoid, hence one description class. This is a theorem about the chosen formal description language. It does not require a ground-level collapse, and it does not rule out a richer explicit grammar whose declared content distinguishes lifts.

## Conditional grammar policy

`IFG_P1` is accordingly retained as a revisable **descriptive belt grammar**: it types a branch of grammar-level mode-flows for conditional downstream analysis. It does not constitute modes, exhaust their possible content, or derive its own applicability from the ground.

## Description-fidelity discipline

A formal grammar earns downstream use only by explicit, defeasible criteria:

1. **Internal coherence:** stated structures and quotients are mathematically consistent.
2. **Type discipline:** it does not represent the ground as a formal object or silently reify coordinate labels.
3. **Invariance:** claimed descriptions survive declared representation changes.
4. **Target adequacy:** it realizes explicitly stated finite self-presentation, record, or physical target conditions.
5. **Comparative/discriminating value:** it outperforms or excludes rivals relative to declared targets, rather than merely being usable.
6. **Scope disclosure:** any unrepresented phenomenological, physical, or normative content remains open rather than denied.

## Result

Revision C is correct as a retyping of the task: formal grammar is appearance-level description, not ground-level ontology. It is incorrect if it withdraws all adequacy/fidelity demands or treats use as sufficient proof of mode correspondence.
