# AP3P1 Bi-Infinite Intrinsic Mode-Flow Grammar v1
## A conditional no-background-time implementation of non-ceasing, non-recurrent finite appearance

## Purpose

AP3O found that an unceasing, non-recurrent intrinsic mode-flow cannot have a nonempty finite phase domain. AP3P1 develops one explicit conditional implementation: a bi-infinite intrinsic successor structure whose phases are finite bounded contexts. It tests whether such a grammar can realize the intended claims without an external time coordinate.

This is a new revisable grammar law. It is not derived from the protected core, AP3N, phenomenology, or physics.

## Candidate phase flow

Use the minimal IAR-like contexts:
\[
C_P=\{0,1,2\},\qquad C_Q=\{0,1,3\},
\]
with their inherited endogenous strict orders. Let phase indices be the abstract order type \(\mathbb Z\), interpreted solely as intrinsic positions in the flow—not as a background physical parameter.

Define:
\[
P_\Phi=\{p_n:n\in\mathbb Z\},
\qquad
p_n\rightsquigarrow p_{n+1},
\]
with phase context:
\[
C(p_n)=
\begin{cases}
C_P,&n\text{ even},\\
C_Q,&n\text{ odd}.
\end{cases}
\]

Each successor pair shares the ordered trace:
\[
\{0,1\},\qquad 0\prec1.
\]

## Decentered history gauge

Let \(\alpha\) exchange contents \(2\leftrightarrow3\) and fix \(0,1\). Define the generator:
\[
g(p_n)=p_{n+1},
\qquad
g(C(p_n))=\alpha(C(p_n)).
\]
Then \(\Gamma_\Phi=\langle g\rangle\cong\mathbb Z\) is declared a **description gauge of phase origin and P/Q alternation**, not a physical time-translation symmetry. It must preserve successor structure, phase order type, and the common trace.

The gauge says no phase is a privileged intrinsic “now.” It does not identify distinct flow components. Different components are distinct finite mode-flows and retain real boundaries.

## Continuation and mode identity

Within this candidate law:
\[
p_n\sim_\Phi p_m
\quad\Longleftrightarrow\quad
p_n,p_m\in P_\Phi,
\]
so phases in one connected bi-infinite successor component are phases of one mode-flow. Distinct components are distinct mode-flows. This explicitly replaces AP3G’s static context-plus-valuation mode identity within this candidate implementation.

## Registered tests

1. Each phase context is finite and proper.
2. Successor has no terminal phase and is acyclic on \(\mathbb Z\).
3. No external time coordinate is present.
4. Every successor pair shares an order-coherent two-content trace.
5. \(\Gamma_\Phi\) is transitive on phase positions and preserves successor, trace, and endogenous order type.
6. The gauge does not map separate flow components to one another.
7. Among the five minimal AP3L families, only IAR-like overlapping triples support every context having an ordered-retentional phase neighbour; therefore this candidate flow grammar has a conditional IAR implementation result.
8. The result is not reported as deriving the continuation law, public records, physical time, or objectivity.

## Scope

A pass establishes only a coherent conditional grammar implementation of the intended mode-flow reading:
\[
\text{finite local phase}\ +\ \text{intrinsic unending flow}\ +\ \text{no privileged phase origin}.
\]
It leaves independent warrant for the bi-infinite order, continuation criterion, gauge interpretation, and phase-to-flow retyping open.
