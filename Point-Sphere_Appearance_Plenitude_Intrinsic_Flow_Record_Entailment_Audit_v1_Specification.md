# AP4D1 Intrinsic-Flow-to-Record Entailment Audit v1
## Does the adopted AP3P1 intrinsic-flow postulate recover a record/code law?

## Question

With \(\mathsf{IFG}_{\rm P1}\) adopted as a labelled grammar postulate, test whether its ordered internal trace entails any AP4-style public/stable record structure, in particular AP4C1’s three-witness diagonal trace code.

## Base language

The flow postulate contains only:

- phase positions \(n\in\mathbb Z\);
- phase type P/Q and successor relation;
- finite contexts and shared ordered trace \((r_0,r_1)\);
- phase-origin gauge and connected grammar components.

It contains no witness domain, record function, redundancy relation, perturbation metric, decoder, public accessibility map, or error predicate.

## Matched expansions

Construct two expansions of the same base P1 flow.

### F0 — bare intrinsic flow

No witness/record sort is added. It satisfies IFG_P1 but has no record code or decoding structure.

### F3 — AP4C1-style code extension

Add three independently named witness evaluations, diagonal trace-code equality, a radius-one perturbation model, and majority decoder. This shares exactly the same base phase flow but has the extra AP4C1 law.

## Theorem

Because F0 and F3 have the same IFG_P1 reduct while disagreeing on record/code predicates:
\[
\mathsf{IFG}_{\rm P1}
\not\models
\mathsf{AP4C1RecordLaw}.
\]

The adopted grammar can provide an ordered trace *carrier* for a record law, but does not recover witnesses, publicness, error, redundancy, metric, or correction.

## Interpretation

This is not a defect in the postulate. It is a clean conditional consequence ledger:
\[
\mathsf{IFG}_{\rm P1}+\mathsf{AP4C1}
\Longrightarrow
\text{conditional flow-and-record branch}.
\]
The record law remains a distinct belt law and no public physical objectivity is inferred.
