# AP4D1 Intrinsic-Flow-to-Record Entailment Audit v1 — Report
## The adopted flow grammar carries an ordered trace but does not recover a record/code law

## Question

After adopting \(\mathsf{IFG}_{\rm P1}\) as a labelled intrinsic-flow grammar, does its ordered trace recover AP4C1’s public three-witness diagonal code, or any comparable record structure?

## Matched models

Both models below have the same P1 phase domain, alternating P/Q phase types, intrinsic successor relation, ordered trace, phase-origin gauge, and component rule.

| Structure | Witness domain | Code | Error metric | Decoder | Public interface |
|---|---|---|---|---|---|
| \(F_0\): bare IFG_P1 | none | none | none | none | none |
| \(F_3\): IFG_P1 + AP4C1 | three stipulated witnesses | diagonal trace code | radius-one Hamming | majority | stipulated witness evaluations |

They share the exact flow reduct but disagree on every record-law predicate. Therefore:
\[
\mathsf{IFG}_{\rm P1}
\not\models
\mathsf{AP4C1RecordLaw}.
\]

All executable checks pass.

## Result

The postulated flow gives a potentially useful internal carrier:
\[
\text{ordered two-content trace}.
\]

It does not give:

- a witness domain;
- public accessibility;
- redundant encodings;
- a perturbation/error distinction;
- a code metric;
- a decoder; or
- cross-perspective objectivity.

AP4A remains a conditional implementation fact: under its added universal two-content public-retentional interface requirement, the IAR-like family provides the relevant minimal partner structure. AP4C1 remains a separate conditional record law compatible with the P1 branch, not a consequence of it.

## Downstream consequence

The correct conditional branch is:
\[
\mathsf{IFG}_{\rm P1}
+
\mathsf{AP4C1}
\Longrightarrow
\text{an intrinsic-flow grammar with a stipulated public trace-record law}.
\]

This is useful for further conditional comparison. It is not a physical clock, a public-objectivity theorem, a theory of error, or a Problem-of-Time solution.

## Conclusion

The postulate adoption unblocks downstream work by fixing the grammar branch. It does not collapse the belt: record structure remains a distinguishable added law, so the programme can now compare record enrichments transparently rather than searching indefinitely for the directed-flow derivation.
