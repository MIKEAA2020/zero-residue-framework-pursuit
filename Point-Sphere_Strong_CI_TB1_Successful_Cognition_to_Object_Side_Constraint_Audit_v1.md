# Strong CI Adjudication — TB1 Successful Cognition to Object-Side Constraint Audit v1
## Does non-accidental cognitive success establish even a minimal ontological constraint?

## Status

**TB1 has no profile-neutral pass from an epistemically described success datum alone.** An object-side constraint follows only under a substantive truth/reference bridge; if the object-side relation is included in the datum, the result is definitional rather than a transcendental derivation.

## 1. Correction to the pre-registered datum

The pre-registration wrote:

\[
\mathsf{OCS}:
\exists s,p,o[
\mathsf{CognitivelyEntertains}(s,p)
\land
\mathsf{CorrectOf}(p,o)
\land
\mathsf{NonAccidental}(s,p,o)].
\]

This contains \(o\) and \(\mathsf{CorrectOf}(p,o)\). On an object-relational reading, it already includes the object-side feature TB1 was meant to derive. To prevent a verbal pass, distinguish:

\[
\begin{aligned}
\mathsf{OCS}_{\rm epi}:&\quad
\exists s,p[\mathsf{InquirySuccess}(s,p)\land\mathsf{NonAccidentalSuccess}(s,p)],\\
\mathsf{OCS}_{\rm rel}:&\quad
\exists s,p,o[\mathsf{CorrectOf}(p,o)\land\mathsf{NonAccidental}(s,p,o)].
\end{aligned}
\]

\(\mathsf{OCS}_{\rm epi}\) is the intended epistemic starting datum. \(\mathsf{OCS}_{\rm rel}\) is a strengthened, theory-laden interpretation of it.

## 2. The target remains weak

\[
\mathsf{TSC}_{\min}:
\quad
\text{Reality is not wholly unconstrained relative to successful cognition.}
\]

This target does not entail an external world, correspondence truth, full intelligibility, an aware ground, simplicity, or a selected ultimate profile.

## 3. Four truth/reference packages

| Package | Does it yield TB1? | Reason |
|---|---:|---|
| Correspondence / truthmaker | conditionally yes | Truth/success is grounded in how reality is; this is a substantive object-side bridge |
| Externalist content/reference | conditionally, for relevant contents | Some content individuation depends on environment/object relations; neither all content nor ultimate ontology follows |
| Pragmatic / inquiry-centred | not by itself | Success may be articulated by norms, ideal inquiry, or practice; further realist bridge is required |
| Deflationary / disquotational | not by truth theory alone | Truth talk may add no substantive metaphysical relation; a separate account of content/world is needed |

The table does not identify a uniquely correct theory of truth. It shows that TB1 is not theory-neutral.

## 4. Formal results

### Relational reading

\[
\mathsf{OCS}_{\rm rel}
\Rightarrow
\mathsf{TSC}_{\min}
\]

is available only because the datum already says that a cognition is correct *of* an object/state. It is an unpacking of the chosen semantics, not a newly derived ontological constraint.

### Epistemic reading

\[
\mathsf{OCS}_{\rm epi}
\not\models
\mathsf{TSC}_{\min}.
\]

It needs an added bridge, for example:

\[
\mathsf{OCS}_{\rm epi}
\land
\mathsf{TruthGroundedInReality}
\Rightarrow
\mathsf{TSC}_{\min}.
\tag{TB1-C}
\]

But \(\mathsf{TruthGroundedInReality}\) is a substantive metaphysical/semantic thesis. It cannot be silently treated as a neutral fact about successful cognition.

## 5. Error and nonexistence stress tests

A TB1 argument must accommodate:

1. false thought that remains intentional;
2. thought about fiction, possibility, or nonexistents;
3. internalist accounts that explain content by intrinsic/phenomenal factors;
4. nondual accounts on which object-directedness is a finite presentation, not evidence for an independently external object; and
5. deflationary accounts that accept true assertions without making truth a substantive metaphysical property.

These cases do not refute object-side grounding. They block the inference from intentionality or success alone to a specific truthmaker relation.

## 6. Candidate comparison

| Candidate profile | Can it accommodate a conditional object-side constraint? | Does TB1 select it? |
|---|---:|---:|
| Classical simple ground | yes | no |
| Necessary emanation/plenitude | yes | no |
| Nondual genuine-aspect identity | yes, with a non-external object-side reading | no |
| Whole-first/structural totality | yes | no |
| Deflationary/brute-remainder rival | may reject a substantive TB1 while allowing ordinary truth practice | no |

Even a correspondence-like TB1 pass would at most discriminate against a strong anti-objective semantic rival. It does not discriminate among the substantive ultimate profiles.

## 7. Exact result

\[
\boxed{
\mathsf{OCS}_{\rm epi}
\not\models
\mathsf{TSC}_{\min}.
}
\]

\[
\boxed{
\mathsf{OCS}_{\rm epi}
\land
\mathsf{TruthGroundedInReality}
\Rightarrow
\mathsf{TSC}_{\min},
\quad
\text{but the bridge is held and nondiscriminating.}
}
\]

Thus inverse transcendental TB1 does not currently escape CI0B’s typed-bridge demand.

## 8. Source note

Correspondence, pragmatic, and deflationary approaches to truth assign different metaphysical roles to truth; correspondence-oriented accounts tie truth to how reality is, while deflationary accounts deny that truth itself supplies a substantive explanatory property. See https://plato.stanford.edu/entries/truth/ and https://plato.stanford.edu/entries/truth-deflationary/.

Intentionality and reference theories also divide between external-relational and internal/phenomenal approaches, and intentional thought can concern nonexistent objects. See https://plato.stanford.edu/entries/intentionality/ and https://plato.stanford.edu/entries/reference/.

## 9. Expiry condition

TB1 advances only if a truth/reference account is defended without importing a selected ultimate profile, handles the stress tests, and yields an object-side constraint that treats the fixed candidate profiles symmetrically.

The inverse-transcendental route expires as a selector if TB1 remains a semantic stipulation, adds only \(\mathsf{TSC}_{\min}\), or leaves every substantive ultimate profile equally admissible.

## Nonclaims

This audit does not reject correspondence realism, establish deflationism, deny genuine cognitive success, solve intentionality, prove nondual idealism, or select an ultimate framework. It identifies the first typed bridge as held and currently nondiscriminating.
