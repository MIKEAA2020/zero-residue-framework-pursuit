# AP3A Perspective-Individuation Test v1
## Finite restriction/sheaf diagnostic for nondual modes

## Purpose

AP3 tests the first decisive debt left by the aware-ground adjudication: can bounded, distinct perspectives be formally represented without introducing independently existing substances?

This is a finite structural diagnostic, not a model of the ground, consciousness, persons, spacetime, or physical dynamics. It supplies only a minimum consistency test for the following requirements:

1. **identity:** perspectives must be distinguishable by non-arbitrary relational/access structure, not labels alone;
2. **bounded access:** each perspective fails to determine the whole global formal state;
3. **public compatibility:** perspectives agree on an explicit overlap/record interface;
4. **non-independence:** local states must be restrictions of a single global state, not independently postulated local ontologies.

## Frozen formal analogue

Let the global formal state space be
\[
X=\{0,1\}^V,\qquad V=\{0,1,2,3,4,5\}.
\]
This \(X\) is **not** the metaphysical ground. It is a finite analogue of a realised aspect with globally coherent relational content.

The fixed global relational graph has edges
\[
E=\{(0,3),(0,4),(1,3),(1,5),(2,3),(2,4),(2,5),(3,4)\}.
\]
Its full automorphism group must be trivial, so the formal roles are relationally, not merely nominally, distinguishable.

Define two candidate perspective carriers and their public overlap:
\[
V_P=\{0,1,2,3,4\},\qquad
V_Q=\{0,1,2,3,5\},\qquad
O=V_P\cap V_Q=\{0,1,2,3\}.
\]
The local perspective maps are restrictions
\[
\pi_P:X\to\{0,1\}^{V_P},\qquad
\pi_Q:X\to\{0,1\}^{V_Q}.
\]

## Registered conditions

### I — structural identity

- The global graph has exactly one automorphism.
- The induced carrier graphs on \(V_P\) and \(V_Q\) are not isomorphic.
- Therefore P and Q are not only differently named copies of the same formal access profile.

### B — bounded access

- Each restriction map has two-element fibres.
- There exist distinct global states with the same P-local state, and likewise for Q.

### R — public-record compatibility

For every global state \(x\), the two local restrictions agree exactly on \(O\):
\[
\pi_P(x)|_O=\pi_Q(x)|_O.
\]

### N — non-independent amalgamation

The compatible local-pair space is exactly
\[
\bigl\{(p,q):p|_O=q|_O\bigr\}.
\]
Every compatible pair has one and only one global amalgamation in \(X\); incompatible local pairs have none. Hence local descriptions are neither two free global states nor ontologically self-sufficient in the formal model.

## Interpretation rule

A passing result establishes only this:

> Distinct, bounded, publicly compatible local profiles can be realised as non-independent restrictions of one relational global formal state.

It does not establish that an actual simple ground has parts, that local profiles are conscious subjects, that graph nodes are substances, or that the global state is metaphysically identical to the ground. AP3B must still supply an aspect/mode interpretation and an account of phenomenality.
