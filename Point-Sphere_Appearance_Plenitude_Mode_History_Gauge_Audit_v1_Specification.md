# AP4C3E1 Mode-History Gauge Audit v1
## Does existing Point–Sphere structure supply a decentered invariant persistence relation?

## Purpose

The ego-decentering proposal correctly warns against treating a finite mode’s local persistence-story as absolutely authoritative. The relevant formal question is not whether every persistence account is arbitrary, but whether existing AP3/AP4 structure supplies a declared action on mode histories whose invariants distinguish a decentered continuation description from a merely local one.

This audit tests that question in the existing finite AP3L/AP3N/IAR resources. It does not import a new physical dynamics, external time, mode carrier, or global identity relation.

## Required data for a gauge-relative persistence theorem

A genuine result would require:
\[
\Gamma_{\rm pers}\curvearrowright\mathcal H,
\qquad
\mathcal I(\mathcal H/\Gamma_{\rm pers}),
\]
where \(\mathcal H\) is a specified class of mode histories or non-temporal transition structures, \(\Gamma_{\rm pers}\) acts on those histories, and \(\mathcal I\) supplies invariant continuation facts.

Existing resources must therefore be distinguished:

1. **AP3G description gauge:** \(K=\mathbb Z_2\) changes only redundant label \(u\) in \([C,\nu,u]_K\); it leaves context \(C\) and valuation \(\nu\) fixed.
2. **AP3L \(S_4\) quotient:** quotient of labelled *grammar descriptions* for structural-family classification. It is not declared as an in-model gauge identifying contexts/modes.
3. **Graph automorphisms:** symmetries of a particular unvalued compatibility skeleton. They are candidate structural symmetries only unless a separate gauge interpretation is supplied.
4. **AP3N order:** an internal order \(\prec_C\) with overlap coherence; it is not an action on histories or a persistence relation.

## IAR test case

In the AP4 minimal presentation let:
\[
C=\{0,1,2\},\qquad D=\{0,1,3\},
\]
with the shared ordered trace \(0\prec1\). Compare four candidate continuation verdicts:

- exact-context identity: \(C=D\);
- shared ordered-trace continuation: a common ordered pair exists;
- retentional-order-type continuation: \((C,\prec_C)\cong(D,\prec_D)\);
- compatibility-automorphism continuation: some \(\alpha\in\operatorname{Aut}(G)\) sends \(C\) to \(D\).

The audit tests whether existing gauge data selects one of these as physical/presentational identity.

## Registered tests

1. Compute compatibility-graph automorphism groups and their maximal-context orbits for all five families.
2. Verify that the IAR-like compatibility automorphism swapping contents \(2,3\) maps \(C\) to \(D\).
3. Verify that AP3G’s actual \(\mathbb Z_2\) description gauge does not map \(C_P\) to \(C_Q\).
4. Show that the candidate continuation rules disagree on the IAR pair while all preserve the existing static AP3 data.
5. Check whether treating graph automorphism orbits as mode gauge would collapse distinct maximal contexts contrary to the AP3G rule that mode identity includes its context and valuation.
6. Register that no existing object is a declared \(\Gamma_{\rm pers}\)-action on histories and no invariant continuation observable is supplied.

## Interpretation rule

If the audit finds only untyped automorphisms and competing candidate relations, then ego-decentering motivates—but does not yet derive—a gauge-relative persistence theory. A future persistence law must state whether its action is gauge or physical symmetry, preserve real finite boundaries, and give a noncircular criterion of continuation that does not simply treat one mode’s own story as absolute.
