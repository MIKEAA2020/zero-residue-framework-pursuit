# G3/CFD Exploratory Web Pilot P1 v1
## Fixed archival eligibility screen: first ten post-training public DES samples

## Status

**Exploratory document-eligibility screen only. No item is Core-scored, phenomenally certified, or used as confirmatory data.**

This pilot tests whether a fixed public archival selection has the information required even to enter the complete-mode G3 classifier.

## 1. Frozen source and selection rule

- Source index: `https://hurlburt.faculty.unlv.edu/ieo/sadie/sadie_sampling.html`
- Source family: public DES sampling summaries and linked transcripts
- Selection rule: select the first ten sample identifiers in chronological order after the source's first sampling-day interview:

\[
\{2.1,2.2,2.3,2.4,2.5,2.6,3.1,3.2,3.3,3.4\}.
\]

The selection is fixed by chronological position, not by apparent fit with CFD. This does not make the material confirmatory: the source remains archival and does not implement the preregistered prospective neutral completion instrument.

## 2. Screen rule

Each item is assessed only for the frozen manual's entry conditions:

\[
C1\text{--}C6.
\]

The screen asks:

\[
\text{Does the public source itself provide a unique complete finite quality-by-phase,}\
\text{order, locus, equality, and negative-literal coding without theoretical enrichment?}
\]

If no, the item receives:

\[
\mathsf{OutOfScope}_{\rm incomplete}.
\]

No Core computation occurs after an out-of-scope result.

## 4. Exact exploratory finding

For this frozen archival selection:

\[
\boxed{
10/10\text{ items fail G3 complete-mode entry because the source does not supply the structured}\
\text{completion matrix required by }C2\text{--}C4.
}
\]

This is a source-interface finding:

\[
\text{DES summary/transcript description}
\not\Rightarrow
\text{G3 complete-mode data format}.
\]

It is not a selector-performance result:

\[
\text{out of scope}
\not\Rightarrow
\neg\mathsf{Core}^{\rm cmp},
\qquad
\text{out of scope}
\not\Rightarrow
\neg\mathsf{Aspect}^{\Phi}_{G}.
\]

## 5. Consequence for web acquisition

The web can provide rich archival first-person material. It cannot, on the reviewed source, supply a confirmatory G3 corpus without changing the protocol or adding new data collection.

That limitation is not cured by more permissive coding. Relaxing completion after seeing these cases would violate the frozen manual.

## Nonclaims

This ten-item exploratory screen is not a prevalence estimate, not a criticism of DES, not evidence for a rival, not a result about phenomenal unity, and not a reason to amend the confirmatory protocol.
