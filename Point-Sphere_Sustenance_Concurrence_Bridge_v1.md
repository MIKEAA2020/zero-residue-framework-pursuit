# Sustenance–Concurrence Bridge v1
## C1c: minimal typed two-level bridge

## Scope box

**Assumed for internal programme work:** real dependent creation and the protected hard core.

**Question:** can a minimal formal architecture distinguish ontological sustenance from a competing created efficient cause while retaining real finite causal differences?

**Not claimed:** a proof that sustenance exists, a full metaphysics of divine action, a solution to freedom or evil, a realization-rule choice, or a physical theory.

---

## 1. Three typed explanatory roles

Fix a realization candidate \(R\), an actual created totality \(T\), and a created structural model
\[
\mathcal M_T=(\mathcal X,\mathcal U,\mathcal F,P(\mathcal U)).
\]

A created history \(h\) is a sequence of assignments satisfying \(\mathcal F\) for an exogenous context \(u\), with optional created interventions \(do(I=i)\).

The bridge distinguishes—not identifies—three roles:

| Role | Typed expression | What it answers |
|---|---|---|
| Realization | \(\mathsf{Real}_R(T)\) | Why this totality/model belongs to the realized creation, rather than another admissible totality |
| Created differentiation | \(\mathcal M_T,u,do(I=i)\models X_j=x\) | Why this created variable has this value, and how an intervention changes later created values |
| Sustenance | \(\mathsf{Sustain}_E(\langle T,h,e\rangle)\) | Why this created event/token is actual at all rather than lacking created being |

The formal separation prevents C1 from smuggling a realization selection into the sustenance relation, or treating sustenance as an extra physical input.

## 2. Explicit bridge laws

### B1 — actual-created-event law

For a candidate event token \(e=(X_j=x,t)\) in a history \(h\):
\[
\mathsf{ActualCr}(e)
\iff
\mathsf{Real}_R(T)\ \land\ \mathsf{Run}(\mathcal M_T,u,do(I=i),h)\ \land\ \mathsf{Sustain}_E(\langle T,h,e\rangle).
\]

The right-hand conjuncts have different types. `Run` supplies a created value/dependence explanation; `Sustain` supplies the ontological actualness condition; `Real` locates the totality in the realization layer.

### B2 — parent-set exclusion

For each created equation \(X_j=F_j(\mathrm{Pa}_j,U_j)\),
\[
E\notin\mathrm{Pa}_j,
\qquad
\mathsf{Sustain}_E\notin\operatorname{dom}(F_j).
\]

Thus sustenance is not a rival created variable that combines with finite causes to produce a value.

### B3 — counterfactual preservation

For fixed \(T\), \(u\), and two created interventions \(do(I=i)\), \(do(I=i')\), if the created SCM gives different descendants, then the bridge must preserve that difference:
\[
\mathcal M_T,u,do(I=i)\models X_j=x
\ \not\equiv\
\mathcal M_T,u,do(I=i')\models X_j=x'
\quad\Longrightarrow\quad x\ne x'.
\]
Sustenance applies to the created tokens in both admissible histories; it does not collapse their distinct created values.

### B4 — totality/selection non-substitution

Within a fixed \(T\), \(\mathsf{Sustain}_E\) does not select among alternative \(T\)'s or replace the open R-layer bridge. Claims that it does so must be typed as a realization-rule proposal and tested in R, not silently added to C1.

---

## 3. Why this is more than “different levels”

The bridge has a checkable division of labour:

- delete \(\mathsf{Sustain}_E\), and no event qualifies as an *actual created* event under B1, even though \(\mathcal M_T\) remains a mathematical/counterfactual specification;
- delete or alter a created equation/intervention, and the differentiated created outcome changes under B3, although the sustenance relation has not supplied the changed value; and
- replace \(T\), and the issue is realization, not an intervention within one created model.

This is a minimal ontological semantics. It makes the concurrence proposal intelligible as a type distinction but does not yet explain why \(\mathsf{Sustain}_E\) is metaphysically necessary, why finite agents act freely, or why a good ground sustains harmful events.

## 4. Frozen finite bridge check

`point_sphere_sustenance_concurrence_bridge_v1.py` uses the C1a finite SCM. It represents two histories generated by distinct interventions on a finite action. For each history, it constructs created event tokens and applies B1 only when the registered realization, created run, and sustenance conditions hold.

Required checks:

1. every registered actual-created event satisfies B1;
2. the created parent sets do not include the ground or the sustenance relation;
3. two action interventions retain distinct later public values;
4. both distinct histories retain their own sustained event tokens;
5. local perspectives remain partial; and
6. negative valence remains present in at least one sustained history.

## 5. Failure conditions

The bridge fails if it represents the ground as an ordinary created causal input, leaves no difference between \(\mathsf{Sustain}_E\) and a decorative tag, collapses intervention-difference, assigns realization selection to sustenance without an R-layer rule, or removes finite ignorance/harm from the actual-created event set.

## 6. Residual debt

Passing the finite check would establish only that the typed laws are jointly implementable in a toy. The unresolved substantive debt is a metaphysical account of B1’s ontological force: why dependence is not just a relabelling of the already-specified model, and how the ground’s assumed goodness relates to sustained harmful events. Those are later C/E-belt tasks, not discharged here.
